# Codex 开发任务：闲鱼低价实用软件产品线

## 目标
把本仓库推进为可以实际销售的低价实用软件产品工厂。第一阶段排除 AI 简历类产品，面向中国大陆普通用户和闲鱼低客单价走量场景。

## 第一批
1. 文本批处理器
2. CSV 数据清洗器
3. 报价利润核算器
4. 图片压缩调整器
5. 批量文件名生成器
6. 日期/工作日计算器

## Codex 必须完成
1. 先审查 README、AUTOMATION_STATUS、src、apps、server、tools、tests、docs、site、config，不要推翻已有可复用代码。
2. 为 6 个产品建立独立、可维护的产品目录，中文 UI、Windows 友好、无需登录、核心功能离线、错误提示清晰、隐私优先。
3. 每个产品必须有 README/使用说明书、CHANGELOG、必要的依赖说明、基本测试。
4. 优先做 Windows EXE/安装包；如果当前环境不能可靠生成 EXE，必须写明原因并提供可复现的 Windows 构建 workflow，禁止虚构产物。
5. 建立 products/ 与 manifest，记录 product_id、版本、功能、系统要求、文件清单、SHA256、价格区间、套餐归属。
6. 建立单品、3工具组合、全套工具包三档交付结构，并生成真实可用的闲鱼商品说明、FAQ、交付说明，不虚构功能。
7. 加入 GitHub Actions：测试、构建、打包、产物校验。
8. 使用 feature 分支，不直接破坏 main；完成后 commit 并创建 PR。PR 必须写明测试命令、结果、产物位置、已知限制。
9. 不得提交任何密钥、Token、支付信息。

## 完成标准
只有在“可运行、核心功能可用、测试通过、构建/打包通过、有说明书、有版本号、有 SHA256、有可交付产物、有 PR”全部满足后，才算第一批完成。

## 后续
第一批完成后继续第二批，优先 PDF、图片/文件批处理、表格数据处理、报价/订单辅助、文件整理/本地隐私工具；避免 AI 简历和泛 AI 聊天套壳。

## 执行要求
不要停留在方案讨论。直接检查仓库、实现、测试、打包并提交 PR。遇到阻碍选择可落地替代方案并记录原因。
