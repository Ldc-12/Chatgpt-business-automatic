# 中国大陆可直接使用版产品策略

## 目标

产品下载后不依赖 ChatGPT、OpenAI、国外 SaaS 或 VPN。优先使用 WPS、Microsoft Excel、手机/电脑本地文件等常见工具。

## 产品本地化原则

- 金额默认使用人民币（¥）
- 日期默认 YYYY-MM-DD
- 示例客户、公司、联系方式使用虚构数据
- 不要求绑定海外账号
- 不把 AI API 作为产品运行前提
- 模板提供空白字段，让买家自行填写
- 涉及财务、求职、客户资料时提醒用户自行核验和保护个人信息

## 首批大陆版

1. 自由职业者应收账款催收管理
2. 小微企业自动化审计表
3. 求职申请追踪器
4. AI 内容工作流规划器（AI 为可选工具，不是必需）
5. 客户入驻/交付管理
6. 会议行动追踪
7. SOP 标准作业流程模板
8. 接单/报价 Pipeline
9. 简易销售客户跟进表
10. 创作者内容日历
11. 家庭财务事务管理
12. AI 编程效率 ROI 表（AI 工具可选）

## 发行方式

海外版继续保留 Stripe。

大陆版应增加适合大陆消费者的支付与交付渠道。支付渠道必须由实际可用的商户/支付账户完成实名认证和合规开通；不要在代码中保存支付密钥。

## 交付原则

付款成功后才授予下载权限。不要把需要付费的文件作为长期公开 URL 暴露。

当前 GitHub Pages 版本仅作为产品展示和测试交付页面，不应被描述为安全的付费文件保护系统。
