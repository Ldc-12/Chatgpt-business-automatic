完整客户包保留全部 20 款业务软件和 1 个工具箱启动器。F 不在分类打包脚本中重复生成，避免出现两套不同版本来源。

## 交付规则

- 每个 A–E 分类 ZIP 均包含该系列全部 EXE、每款对应的中文说明书和系列说明。
- 单品 ZIP 继续包含对应 EXE、README 和该产品说明书。
- 分类 ZIP 与全系列包均由同一轮 Windows 构建产物生成，避免跨版本混装。
- 软件本地运行，不依赖 VPN、ChatGPT 或外部 AI。
- 数据默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\\MainlandBusinessTools`。
- 首次运行需显示设备码；每款软件使用独立授权文件。卖家密钥不进入客户包。
