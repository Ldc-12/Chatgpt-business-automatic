# 闲鱼大陆版销售方案

## 定价策略（大陆测试阶段）

本项目不再沿用海外数字产品的美元定价直接换算人民币。

参考当前大陆模板/数字资料市场信号，普通单个 Excel/文档模板常见低价区间约 5–25 元；闲鱼虚拟资料常见 9.9 元引流、19.9–29.9 元作为小合集/主力档位，更完整的大合集才适合继续向上定价。第三方市场资料也显示，普通模板与专业/定制服务的价格差异很大，因此不能因为“看起来功能多”就直接定高价。

### 当前测试价
- 9.9 元：Meeting Action Tracker
- 12.9 元：Job Search Application Tracker Pro、Personal Finance Admin Tracker
- 19.9 元：大多数职场/自由职业/内容运营工具包
- 29.9 元：Small Business Automation Audit Kit

这些是**测试成交价，不是产品价值的最终判断**。如果真实询盘和成交证明某个产品的内容深度、节省时间价值和复购/组合价值更高，再逐步提高价格。

## 产品价值标准

单纯“几个空白 Excel 表”不值高价。因此大陆版产品需要逐步升级为：
- 可直接使用的 Excel/WPS 文件
- 已填好的真实场景示例数据
- 使用说明
- 操作步骤
- 检查清单
- 计算公式/自动化字段（适用时）
- 一页快速上手指南
- 可复制的话术/模板（适用时）
- 版本更新记录

目标是让买家购买的是“解决一个具体问题的一套工具”，而不是“一个文件”。

## 第一阶段不要追求高客单

先验证：
1. 曝光后是否有人咨询
2. 咨询后是否愿意支付 9.9–29.9 元
3. 买家实际使用时卡在哪里
4. 哪些字段/功能最有价值
5. 哪些产品适合组合成 39.9–59.9 元套餐

只有真实数据支持时才提价。

## 闲鱼交付

普通账号测试阶段按平台允许的方式交付，不绕过闲鱼支付和平台规则。正式虚拟商品自动化需要以当前闲鱼开放平台的准入、审核和类目规则为准。

## 风险边界

- 不承诺赚钱、涨粉、成交、求职成功等结果。
- 不销售未经授权的第三方资料。
- 不用虚假销量、虚假评价或虚假效果。
- 海外 Stripe 版本与大陆闲鱼版本分开。
