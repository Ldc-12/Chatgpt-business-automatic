# 实用效率工具箱｜用户说明书

## 一、产品用途
“实用效率工具箱”是统一启动入口，用于集中打开同一套产品包中的 Windows 工具。请将工具箱 EXE 与套餐内其他 EXE 解压到同一个文件夹，不要只单独移动工具箱。

## 二、基本操作
1. 解压购买的套餐 ZIP，保持所有 EXE 在同一目录。
2. 双击“实用效率工具箱.exe”。
3. 在列表中找到需要使用的工具，点击“启动”。
4. 工具关闭后，可再次从启动器打开其他工具。

## 四、注意事项
- 如果提示某工具未包含在当前套餐中，说明该 EXE 不在当前购买版本。
- 请勿移动或重命名同一套餐内的 EXE 文件；启动器会从自身所在目录寻找其他工具。
- 数据和各工具的具体使用方式以对应产品说明书为准。
- 本产品为 Windows 本地工具，不要求 ChatGPT、VPN 或外部 AI 服务。
