# 实用效率工具箱｜用户说明书

## 一、产品用途
“实用效率工具箱”是统一启动入口，用于集中打开已安装在同一套产品包中的 Windows 工具。

## 二、基本操作
1. 打开“实用效率工具箱”。
2. 在列表中选择需要使用的工具。
3. 点击启动。
4. 工具关闭后，可再次从启动器打开其他工具。

## 三、工具列表
启动器当前对应：文件整理、图片批处理、PDF 批处理、自由职业催款、客户跟进、求职管理、小微企业经营收支、会议行动项、SOP 项目执行。

## 四、注意事项
- 如果提示某工具未包含在当前套餐中，说明该 EXE 不在当前购买版本。
- 建议不要移动或重命名同一套餐内的 EXE 文件，否则启动器可能找不到对应程序。
- 数据和各工具的具体使用方式以对应产品说明书为准。

## 五、版本
当前说明书对应：实用效率工具箱。
