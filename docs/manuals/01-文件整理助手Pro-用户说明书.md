# 文件整理助手 Pro 1.1｜用户说明书

## 1. 产品用途
把一个文件夹中的常见文件按类型自动归类，减少桌面、下载目录和工作目录杂乱。

## 2. 支持分类
图片、视频、音频、文档、压缩包、程序、其他。

## 3. 基本操作
1. 打开“文件整理助手 Pro”。
2. 选择需要整理的文件夹。
3. 点击扫描/预览，先确认文件数量。
4. 如需处理子文件夹，勾选“包含子文件夹”。
5. 点击开始整理。
6. 完成后按分类文件夹检查结果。
7. 可查看“整理记录.json”。

## 4. 撤销
软件会记录最近一次整理动作。使用“撤销最近整理”可尝试恢复最近一次移动。执行前不要删除、改名或再次移动相关文件。

## 5. 重名处理
目标位置已有同名文件时，不会直接覆盖，会自动生成类似“文件 (1).jpg”的新名称。

## 6. 注意事项
- 第一次使用建议先用测试文件夹。
- 不建议直接整理 Windows 系统目录、程序安装目录或正在运行软件的工作目录。
- 以“~$”或“.”开头的临时/隐藏类文件会被跳过。
- 请确认目标文件夹具有读写权限。

## 7. 常见问题
**整理后文件在哪里？** 按图片、视频、音频、文档等分类文件夹查找，并可查看整理记录。

**会覆盖同名文件吗？** 不会，软件会自动生成不重复的文件名。

**可以恢复吗？** 可以使用撤销功能，但前提是记录及相关文件仍然存在且没有被再次移动。
