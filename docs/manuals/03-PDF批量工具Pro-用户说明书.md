# PDF 批量工具 Pro 1.1｜用户说明书

## 一、产品用途
用于在 Windows 电脑上批量合并 PDF、拆分 PDF，以及快速查看 PDF 页数。

## 二、主要功能
- 批量/多文件合并 PDF
- PDF 拆分为单页文件
- 扫描并显示 PDF 页数
- 自动排除历史输出文件

## 三、合并 PDF
1. 打开软件并选择包含 PDF 的文件夹。
2. 扫描文件。
3. 确认待合并文件列表。
4. 点击“合并 PDF”。
5. 软件生成“合并结果.pdf”。
6. 如目标文件已存在，软件会在覆盖前进行确认。

合并顺序以软件扫描后显示的文件顺序为准，正式合并前建议确认列表。

## 四、拆分 PDF
1. 选择 PDF 文件夹。
2. 扫描。
3. 选择需要拆分的 PDF。
4. 点击拆分。
5. 软件会在“拆分结果”目录生成单页 PDF。

## 五、页数查看
扫描后可查看每个 PDF 的页数，适合在合并或拆分前快速检查文件。

## 六、注意事项
- PDF 文件需要能够正常读取。
- 不建议同时用其他软件修改正在处理的 PDF。
- 重要文件处理前建议保留原始备份。
- 合并前建议确认文件顺序。

## 七、常见问题
**Q：为什么某个 PDF 没有被处理？**  
A：请检查文件是否损坏、是否正在被其他程序占用，以及文件扩展名是否为 PDF。

**Q：拆分后的文件在哪里？**  
A：默认在源文件夹下的“拆分结果”目录。

**Q：合并结果会覆盖原来的结果吗？**  
A：软件会先检测已有“合并结果.pdf”，覆盖前需要确认。
