# 轻量销售客户跟进工具｜用户说明书

## 一、产品用途
用于记录客户、销售线索、跟进日期、沟通情况和下一步行动，适合个人销售、小团队和个体经营者。

## 二、基本流程
1. 建立客户/线索。
2. 填写来源、联系人及当前阶段。
3. 每次沟通后更新跟进记录。
4. 设置下一次跟进时间。
5. 定期检查待跟进客户。

## 三、建议的客户阶段
可以按照自己的业务流程使用，例如：新线索、已联系、需求确认、报价、谈判、成交、暂缓、未成交。

## 四、数据保存、备份与恢复
- 每次新增、编辑、删除或导入后，程序会自动保存到本机：`%LOCALAPPDATA%\MainlandBusinessTools\sales.json`。
- **JSON备份**：点击工具栏“JSON备份”，选择保存位置。JSON备份保留完整字段，适合迁移电脑或长期留档。
- **JSON恢复**：点击“JSON恢复”，选择之前保存的 JSON 备份。恢复会替换当前客户列表；确认后程序会先把恢复前的数据自动另存为 `sales.json.before-restore-时间戳.json`。
- **CSV 导出**：使用 UTF-8 BOM，适合 Excel/WPS 打开；对可能被识别为公式的文本（忽略前导空格、制表符和换行后以 `=`、`+`、`-`、`@` 开头）自动添加文本前缀。导出先生成完整内容，再写入同目录临时文件并原子替换；失败时保留原 CSV。
- **CSV 导入**：采用整批校验，必须包含且只能包含规定字段；重复表头、额外列、缺失列、字段数量不一致、非法金额都会拒绝。单个 CSV 最大 25 MiB、最多 50,000 条记录。由本软件导出的公式安全前缀会在重新导入时还原，避免改变原始客户资料。
- 导入前会显示替换确认；如果本机已有数据，程序会先自动保存 `sales.json.before-csv-import-时间戳.json`，再原子替换当前数据。备份或写入失败时不会替换现有数据。
- 如果本机数据文件损坏，程序会提示读取失败并保留原文件，不会静默覆盖为空列表；可用“JSON恢复”载入有效备份。
- 备份文件建议另存到 U 盘或其他电脑，避免只留在原电脑。

## 五、注意事项
- 客户资料可能包含个人信息，请妥善保管备份文件。
- 阶段名称应保持统一，方便后续统计和筛选。
- 本工具为单机记录工具，不提供多人协作、云同步或自动联系客户功能。

## 六、常见问题
**Q：适合企业吗？**  
A：适合个人和小团队轻量使用；大型团队的权限、审计和多人协作需求需要专业 CRM。

**Q：能自动联系客户吗？**  
A：本工具定位为本地客户跟进记录，不等于自动营销系统。
