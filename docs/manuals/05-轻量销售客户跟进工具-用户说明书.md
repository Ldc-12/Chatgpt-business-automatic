# 轻量销售客户跟进工具｜用户说明书

## 一、产品用途
用于记录客户、销售线索、跟进日期、沟通情况和下一步行动，适合个人销售、小团队和个体经营者。

## 二、基本流程
1. 建立客户/线索。
2. 填写来源、联系人及当前阶段。
3. 每次沟通后更新跟进记录。
4. 设置下一次跟进时间。
5. 定期检查待跟进客户。

## 三、建议的客户阶段
可以按照自己的业务流程使用，例如：新线索、已联系、需求确认、报价、谈判、成交、暂缓、未成交。

## 四、注意事项
- 客户资料建议定期备份。
- 不要把重要客户数据仅保存在一台电脑。
- 阶段名称应保持统一，方便后续统计和筛选。

## 五、常见问题
**Q：适合企业吗？**  
A：适合个人和小团队轻量使用；大型团队的权限、审计和多人协作需求需要专业 CRM。

**Q：能自动联系客户吗？**  
A：本工具定位为本地客户跟进记录，不等于自动营销系统。
