# 求职申请管理 Pro｜用户说明书

## 一、产品用途
用于集中记录投递过的职位、公司、申请日期、招聘阶段和后续行动，减少漏投、重复投递和忘记跟进。

## 二、推荐流程
1. 新增职位申请。
2. 填写公司、岗位、申请日期等信息。
3. 根据招聘进展更新状态。
4. 记录面试、沟通和后续事项。
5. 定期查看需要跟进的申请。

## 三、建议状态
可按个人习惯设置为：待投递、已投递、笔试、面试、复试、Offer、已入职、拒绝、暂停等。

## 四、注意事项
- 简历和个人信息属于敏感资料，建议妥善保管。
- 重要招聘信息建议同时保留原邮件或招聘平台记录。
- 本工具是申请管理工具，不提供招聘结果保证。

## 五、常见问题
**Q：适合一次投很多岗位吗？**  
A：适合，核心用途就是集中管理大量申请记录。

**Q：数据会自动上传吗？**  
A：本地工具的设计目标是本机管理，不应把个人求职资料当作公开数据使用。

## 六、版本
