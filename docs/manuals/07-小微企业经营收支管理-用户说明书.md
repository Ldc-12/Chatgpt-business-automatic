# 小微企业经营收支管理｜用户说明书

## 一、产品用途
用于小微经营者记录日常收入、支出和经营流水，帮助快速了解资金收支情况。

## 二、基本操作
1. 打开软件。
2. 按实际发生情况录入收入或支出。
3. 填写日期、项目和金额。
4. 定期检查记录。
5. 按需要备份数据。

## 三、使用建议
建议每天或每周固定时间录入，不要长期积压后一次性补记。

## 四、注意事项
- 本工具用于经营记录和辅助管理，不替代依法应使用的会计、税务系统。
- 账务数据请定期备份。
- 金额、日期、收入/支出方向务必核对。

## 五、常见问题
**Q：可以用于正式报税吗？**  
A：不能把本工具视为专业税务申报软件；正式申报请依据当地税务要求使用相应系统。

**Q：适合谁？**  
A：个体经营者、小微商家、自由职业者和需要轻量流水记录的用户。

## 六、版本
当前版本以软件实际显示版本为准。
