# 会议行动项管理｜用户说明书

## 一、产品用途
用于把会议中的任务、负责人、截止日期和完成情况集中记录，减少“开完会就忘”的情况。

## 二、推荐流程
1. 创建会议记录。
2. 记录会议主题和日期。
3. 将讨论结果转成具体行动项。
4. 为行动项填写负责人和截止日期。
5. 完成后更新状态。
6. 会后定期检查未完成项目。

## 三、行动项填写原则
尽量写成可执行动作，例如“整理报价并发送客户”，而不是只写“报价”。

## 四、注意事项
- 负责人和截止日期应尽量明确。
- 会议记录建议定期备份。
- 软件用于任务跟踪，不替代企业正式审批或项目管理系统。

## 五、常见问题
**Q：适合个人使用吗？**  
A：可以，也适合小团队进行轻量会议任务管理。

**Q：会议结束后还能补录吗？**  
A：可以，重点是把最终确定的行动项补充完整。
