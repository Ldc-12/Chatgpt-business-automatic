# SOP 项目执行管理｜用户说明书

## 一、产品用途
用于把重复性工作整理成标准步骤，并记录执行进度，适合小团队、个体经营者和需要标准化工作的用户。

## 二、推荐使用流程
1. 创建一个 SOP/项目。
2. 写清楚目标和执行范围。
3. 将工作拆成连续步骤。
4. 为步骤设置负责人或备注。
5. 按执行情况更新状态。
6. 完成后复盘并修改 SOP。

## 三、SOP 编写建议
每一步尽量使用明确动作，例如“打开订单表→核对订单号→保存 PDF→发送客户”，避免只写“处理订单”。

## 四、注意事项
- 首次建立 SOP 时可以先做简单版本，再根据实际执行修改。
- 涉及公司机密、客户信息时应注意权限和备份。
- 软件用于轻量流程管理，不等同于大型 BPM/企业流程系统。

## 五、常见问题
**Q：适合哪些场景？**  
A：电商发货、客户 onboarding、内容发布、行政工作、项目交付、店铺日常操作等重复流程。

**Q：SOP 可以不断修改吗？**  
A：可以，建议每完成一轮实际执行后，根据问题持续优化。

## 六、版本
