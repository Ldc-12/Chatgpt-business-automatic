# 小店库存盘点助手｜用户说明书

## 适用场景
适合便利店、网店、小工作室和小微商家记录商品编码、库存数量、预警下限及进货单价。软件在本机运行，不依赖 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用
1. 双击“小店库存盘点助手.exe”。
2. 首次启动会显示设备码；购买授权后，将卖家提供的“小店库存盘点助手.json”放入：
   `%LOCALAPPDATA%\\MainlandBusinessTools\\licenses\\`
3. 点击“新增商品”，填写唯一商品编码和名称；数量、预警下限、进货单价必须为非负有限数字。
4. 数据自动保存到 `%LOCALAPPDATA%\\MainlandBusinessTools\\inventory.json`。

## 日常操作
- 新增商品：商品编码必须唯一，建议使用 SKU 或自定义编号。
- 编辑/删除：先在列表选中商品，再执行对应操作。
- 搜索：可按编码、名称、分类或备注筛选。
- 库存预警：列表下方显示库存数量小于或等于预警下限的商品数量。
- 保存采用同目录临时文件、写入同步和原子替换；保存失败时旧数据和当前内存数据保持不变。

## CSV 导入与导出
CSV 必须且只能包含以下全部列名：商品编码、商品名称、分类、单位、库存数量、预警下限、进货单价、备注。支持 UTF-8/UTF-8 BOM。
- 导入采用追加模式，不覆盖现有数据；重复编码、重复/多余表头、缺少字段、列数不一致或无效数字会整批拒绝。
- 单个 CSV 最大 25 MiB，最多 50,000 条记录；导入后库存总记录最多 100,000 条。
- 导出使用 UTF-8 BOM，自动保护可能被 Excel/WPS 当作公式的文本，并采用原子替换；导出失败时原有文件不会被截断。
- 由本软件导出的公式保护前缀在重新导入时会还原原文本。若客户手工编辑过前缀，请导入后抽查相关文本列。

## 备份与恢复
- 点击“备份”保存 JSON 备份文件，建议定期复制到 U 盘或其他安全位置。
- 库存数据最多 100,000 条，单个备份最大 100 MiB；超限时会提示，不会生成不完整备份。
- 点击“恢复备份”选择备份文件。软件会先检查 JSON 结构、版本、记录字段、商品编码唯一性和数量上限，再由用户确认替换当前库存。
- 恢复采用原子写入；校验或写入失败不会覆盖当前数据，也不会把未保存的恢复内容留在界面内存中。
- 恢复前建议先备份当前数据。不要直接编辑程序目录中的数据文件。

## 注意事项
本软件是轻量库存台账，不是联网多仓 ERP，不会自动同步其他电脑，也不自动计算实时销售出库。请定期备份，并核对实物库存。
