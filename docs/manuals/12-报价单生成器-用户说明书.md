# 报价单生成器｜用户说明书

## 适用场景
适合个体商户、工作室、维修安装服务、自由职业者和小微企业制作规范报价单。软件在 Windows 本机运行，不依赖 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用与授权
1. 双击“报价单生成器.exe”。
2. 首次启动会显示产品设备码。购买授权后，将卖家提供的“报价单生成器.json”放入：
   `%LOCALAPPDATA%\MainlandBusinessTools\licenses\`
3. 报价数据默认保存在：
   `%LOCALAPPDATA%\MainlandBusinessTools\quotations.json`

## 创建报价单
1. 点击“新建报价”，系统按当天日期生成报价单号。
2. 填写客户名称、联系人、联系电话、报价日期、有效期和税率。
3. 点击“添加明细”，填写项目名称、规格型号、单位、数量和单价。
4. 税额与含税总计会自动计算；核对后点击“保存报价”。

## 导出 PDF
点击“导出 PDF”，选择保存位置。生成的 PDF 使用中文字体，可打印或发送给客户。发送前请检查客户资料、数量、单价、税率和有效期；本软件不提供电子签章或合同法律审查。

## CSV 批量导入与导出
- 导出 CSV：每条明细占一行，同一报价单的报价单号、客户和日期等信息会重复写入，方便 Excel/WPS 查看。
- 导入 CSV：相同报价单号的多行会合并成一张报价单；导入采用追加模式，不覆盖现有报价。
- CSV 必须包含完整字段：报价单号、客户名称、联系人、联系电话、报价日期、有效期至、税率(%)、备注、项目名称、规格型号、单位、数量、单价、项目备注。
- 遇到重复报价单号、无效日期、非法数量或同一报价单信息不一致时，整批拒绝导入，不会部分写入。

## 备份与恢复
- 点击“备份”保存 JSON 文件，建议定期复制到 U 盘或其他安全位置。
- 点击“恢复备份”会替换本机全部报价单，软件会再次确认；恢复前建议先备份当前数据。
- 不要直接编辑程序目录内的文件。

## 金额计算说明
未税小计 = 各明细数量 × 单价之和；税额 = 未税小计 × 税率；含税总计 = 未税小计 + 税额。金额按人民币分位四舍五入。软件不自动处理合同条款、预付款、尾款或复杂多税率规则。
