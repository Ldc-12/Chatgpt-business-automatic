# 费用报销管理助手｜用户说明书

## 适用场景
适合个体商户、工作室、小微企业和项目团队整理日常报销、员工垫付、发票状态及付款进度。软件在 Windows 本机运行，不依赖 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用与授权
1. 双击“费用报销管理助手.exe”。
2. 首次启动会显示本产品设备码。购买授权后，将卖家提供的“费用报销管理助手.json”放入：
   `%LOCALAPPDATA%\MainlandBusinessTools\licenses\`
3. 报销数据默认保存在：
   `%LOCALAPPDATA%\MainlandBusinessTools\reimbursements.json`
4. 数据保存在当前 Windows 用户目录，不会自动上传到云端；更换电脑前请先备份。

## 新增报销记录
1. 点击“新增报销”，系统按当天日期生成报销单号。
2. 填写发生日期、报销人、费用类别、费用说明和金额。
3. 金额按人民币元录入，自动按分四舍五入；必须大于 0。
4. 报销状态可选：待提交、已提交、已批准、已付款、已驳回。
5. 选择“已付款”时必须填写付款日期；其他状态可留空。
6. 点击保存。修改或删除前先在主列表选中对应记录。

## 查询与汇总
- 搜索框可查找报销单号、报销人、项目、费用类别、说明和备注等字段。
- 月份筛选填写 YYYY-MM，例如 2026-11。
- 可按报销状态和费用类别筛选。
- 底部汇总显示当前筛选范围的笔数、报销总额、待处理金额和已付款金额。

## CSV 导入与导出
- 导入为追加模式，不覆盖已有记录。
- CSV 必须包含全部规定字段，不能缺列或多列；文件应使用 UTF-8 或 Excel 常见的 UTF-8 BOM 编码。
- 单个 CSV 最大 25 MiB，最多 50,000 条有效记录；超限会在写入前拒绝。
- 遇到重复报销单号、重复/错误表头、多余列、缺少单元格、日期格式错误、金额非法或字段不完整时，整批拒绝，不会部分导入。
- 导出会按当前筛选条件导出，使用 UTF-8 BOM 兼容 Excel/WPS；以公式字符开头的文本会做安全转义，重新导入本软件时会还原原文。

## 备份与恢复
- 点击“备份”保存完整 JSON 备份文件，建议每月及批量导入前备份，并另存到 U 盘。
- 备份最多支持 100,000 笔记录、100 MiB；超过限制会明确提示，不会生成无法恢复的文件。
- 点击“恢复备份”后，软件会先校验备份，并显示备份时间和记录数量，再由你确认是否替换本机全部报销记录。
- 软件会检查备份大小、格式、版本、记录字段和报销单号重复情况；校验失败时不会覆盖现有数据。

## 风险核验与审计报告

工具栏新增“风险核验”和“导出风险报告”，均按当前搜索、月份、状态和费用类别筛选结果执行；先调整筛选范围，再点击核验即可检查指定月份或人员。

当前离线规则集版本：`CN-EXPENSE-2026.11.1`，包含：

- `DUPLICATE_CANDIDATE`：同一报销人、发生日期、费用类别、金额和费用说明完全一致时，将后出现的记录标记为疑似重复，并引用首笔报销单号。系统会规范化全角/半角字符和连续空格；这只是人工核对线索，不代表认定重复或舞弊。
- `INVOICE_MISSING`：发票状态为“无发票”，提示核对费用性质、单位制度和替代凭证。
- `INVOICE_PENDING`：发票状态为“待补票”，提示补票跟进。
- `PENDING_TOO_LONG`：待提交、已提交或已批准记录超过 30 天内部关注期限时提示；超过 60 天会提升为高风险。该期限是软件内置的管理提醒，不是法律或税务期限。
- `PAYMENT_BEFORE_EXPENSE`：付款日期早于费用发生日期时提示核对日期、预付款或冲销场景。

“高/中”表示软件规则的内部提示等级，不是监管评级、法律结论或财务审计意见。实际制度、例外审批和凭证真实性仍须由企业自行判断。

风险报告导出为 UTF-8 BOM CSV，包含规则版本、报销单号、规则编号、风险等级、问题说明、核验依据和建议动作；导出使用原子替换，并对公式型文本做安全转义。即使当前没有规则命中，也可导出只有表头的空报告，留存本次核验结果。

## 注意事项
本软件是本地报销台账和付款进度工具，不是财务软件或税务申报系统。请自行核对发票真伪、报销制度、税务口径和付款凭证；定期备份，不要把唯一数据副本留在电脑桌面。
