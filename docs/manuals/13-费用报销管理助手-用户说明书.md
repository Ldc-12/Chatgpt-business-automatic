# 费用报销管理助手｜用户说明书

## 适用场景
适合个体商户、工作室、小微企业和项目团队整理日常报销、员工垫付、发票状态及付款进度。软件在 Windows 本机运行，不依赖 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用与授权
1. 双击“费用报销管理助手.exe”。
2. 首次启动会显示本产品设备码。购买授权后，将卖家提供的“费用报销管理助手.json”放入：
   `%LOCALAPPDATA%\MainlandBusinessTools\licenses\`
3. 报销数据默认保存在：
   `%LOCALAPPDATA%\MainlandBusinessTools\reimbursements.json`
4. 数据保存在当前 Windows 用户目录，不会自动上传到云端；更换电脑前请先备份。

## 新增报销记录
1. 点击“新增报销”，系统按当天日期生成报销单号。
2. 填写发生日期、报销人、费用类别、费用说明和金额。
3. 金额按人民币元录入，自动按分四舍五入；必须大于 0。
4. 报销状态可选：待提交、已提交、已批准、已付款、已驳回。
5. 选择“已付款”时必须填写付款日期；其他状态可留空。
6. 点击保存。修改或删除前先在主列表选中对应记录。

## 查询与汇总
- 搜索框可查找报销单号、报销人、项目、费用类别、说明和备注等字段。
- 月份筛选填写 YYYY-MM，例如 2026-11。
- 可按报销状态和费用类别筛选。
- 底部汇总显示当前筛选范围的笔数、报销总额、待处理金额和已付款金额。

## CSV 导入与导出
- 导入为追加模式，不覆盖已有记录。
- CSV 必须包含全部规定字段，不能缺列或多列；文件应使用 UTF-8 或 Excel 常见的 UTF-8 BOM 编码。
- 遇到重复报销单号、日期格式错误、金额非法或字段不完整时，整批拒绝，不会部分导入。
- 导出会按当前筛选条件导出；使用 Excel/WPS 打开时可识别中文表头。

## 备份与恢复
- 点击“备份”保存完整 JSON 备份文件，建议每月及批量导入前备份，并另存到 U 盘。
- 点击“恢复备份”会替换本机全部报销记录，恢复前请先备份当前数据。
- 软件会检查备份格式、版本、记录字段和报销单号重复情况；校验失败时不会覆盖现有数据。

## 注意事项
本软件是本地报销台账和付款进度工具，不是财务软件或税务申报系统。请自行核对发票真伪、报销制度、税务口径和付款凭证；定期备份，不要把唯一数据副本留在电脑桌面。
