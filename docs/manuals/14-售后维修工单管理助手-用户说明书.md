# 售后维修工单管理助手｜用户说明书

## 适用场景
适合手机维修、电脑维修、家电维修、数码门店和小型售后服务商记录客户送修、故障、报价、维修进度及取件情况。软件在本机运行，无需 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用
1. 将套餐内的 EXE 放在一个固定文件夹中，双击“售后维修工单管理助手.exe”。
2. 首次启动会显示设备码；购买授权后，将卖家提供的“售后维修工单管理助手.json”放入：
   `%LOCALAPPDATA%\MainlandBusinessTools\licenses\`
3. 点击“新建工单”，填写客户、联系电话、设备/商品和故障描述。系统按登记日期自动生成工单号，例如 `WX20260203-0001`。
4. 工单自动保存到 `%LOCALAPPDATA%\MainlandBusinessTools\repair_orders.json`。

## 工单进度
支持：待检测、待报价、维修中、待取件、已完成、已取消。
将进度改为“已完成”时必须填写完工日期。预约取件日期和完工日期不能早于登记日期。

## 日常操作
- 新建工单：登记客户与设备信息、故障描述、预计费用和预约取件日期。
- 编辑/删除：先选中列表中的工单，再点击相应按钮。
- 搜索：可按工单号、客户姓名、电话、设备、故障描述或备注搜索。
- 筛选：可按登记月份（YYYY-MM）和处理进度筛选。
- 汇总：底部显示当前筛选工单数量、预计费用合计和实收金额合计。

## CSV 导入与导出
CSV 必须包含全部规定字段，列名不能缺失或增加。导入采用追加模式，不覆盖已有工单；遇到重复工单号、非法日期、负数金额或错误进度时整批拒绝，原有数据保持不变。导出会导出当前筛选结果，文件使用 UTF-8 BOM，方便用 Excel 打开中文。

## 备份与恢复
- 点击“备份”保存 JSON 备份文件，建议每周备份并另存到 U 盘或其他安全位置。
- 点击“恢复备份”选择之前保存的 JSON 文件。恢复会替换当前全部工单，软件会再次确认；建议先备份当前数据。
- 数据默认保存在当前 Windows 用户的 LOCALAPPDATA，不要只备份 EXE 所在文件夹。

## 注意事项
本软件是单机工单台账，不会自动发送短信、微信或通知，不会连接维修设备，也不会跨电脑同步。请根据实际检测结果更新工单进度和金额，并定期备份。
