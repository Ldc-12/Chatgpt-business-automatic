# 合同台账与履约风险管理助手｜用户说明书

## 产品用途
面向小微企业、工作室、门店和个人经营者，管理合同资料、续约日期、付款/收款/交付/验收等履约节点，并用本地规则检查常见业务遗漏。软件完全在 Windows 本机运行，不依赖 VPN、ChatGPT、外部 AI、云端服务或外部 API。

## 首次使用与数据位置
双击“合同台账与到期提醒助手.exe”，首次启动按提示完成设备授权。数据保存在当前 Windows 用户目录：
- 合同主表：\`%LOCALAPPDATA%\MainlandBusinessTools\contracts.json\`
- 履约节点和操作记录：\`%LOCALAPPDATA%\MainlandBusinessTools\contract_workflow.json\`

建议每天或每周使用“备份”，并把备份复制到 U 盘或其他安全位置。备份会先写入同目录临时文件，写入完成后再原子替换目标文件；若写入或替换失败，原有备份不会被半截文件覆盖。不要直接用 Excel 修改程序的数据 JSON 文件。

## 新增和维护合同
登记合同编号、名称、甲方/客户、乙方/供应商、签订/生效/到期日期、金额、提前提醒天数、状态、负责人和联系方式。日期使用 \`YYYY-MM-DD\`；生效日期不得晚于到期日期；金额精确到分。合同编号不可重复。

## 建立履约节点
先在主列表选择合同，再点击“履约节点”。可建立以下节点：
- 付款、收款：登记计划日期和金额；
- 交付、验收：登记交付/验收日期和事项；
- 保证金、续约、其他：记录押金退还、续约办理或自定义事项。

节点支持新增、编辑、标记完成和删除。标记完成时会记录完成日期。节点数据与合同编号关联；有履约节点的合同不能直接删除，需先处理关联节点，避免留下孤立记录。

## 风险规则检查
点击“风险检查”，软件按固定规则生成可解释的检查结果：
- 高：待处理节点已经逾期；执行中合同超过登记到期日；付款或收款计划合计超过合同金额；节点关联的合同不存在。
- 中：节点计划日期落在合同期限之外；待处理节点将在 7 天内到期；执行中合同缺少甲方或乙方信息。
- 低：有金额的执行中合同尚未建立履约节点；合同金额为 0，需确认是否为无偿或未录入。

主界面同时显示合同到期提醒、高/中/低风险数量、待付款和待收款金额。付款和收款分别统计，不把两种方向相加。规则结果用于业务核对和提醒，不构成法律意见，也不自动判断合同条款效力；请以签署的合同原件和实际履约情况为准。

## 合同文件批量识别（新增）
点击主界面的“批量识别合同文件”，可一次选择可搜索 PDF、DOCX、TXT 或 MD 文件。软件在本机提取文本，按明确标签识别合同编号、名称、甲乙方、签订/生效/到期日期和金额，并输出 UTF-8 BOM 的“合同识别草稿.csv”。

识别草稿会额外包含来源文件、识别完整度、待补齐字段和规则提示。它不会直接写入正式台账：请先用 Excel/WPS 打开草稿，对照合同原文补齐空白字段、检查金额与日期，再使用“导入 CSV”追加到台账。金额为空时会拒绝导入；无偿合同请明确填写 0。

### 版本化合同核验规则（规则集 CN-CONTRACT-2026.11.1）
识别草稿除字段完整度外，还会输出“规则版本、风险等级、风险命中数、规则提示、风险明细”列。风险明细包含规则编号、风险说明、原文行号/摘录和建议核对动作，便于复核和留档。当前离线规则包括：
- 合同金额：比较明确标注的合同金额/总价/价款字段，发现不同总金额不一致时提示高风险。
- 付款比例：仅汇总包含付款/支付/结算关键词的句段比例；超过 100% 提示高风险，低于 100% 提示中风险，提醒核对是否漏掉尾款或质保金。
- 日期冲突：比较同一类签订、生效、到期日期标签的多处值，并检查生效日期是否晚于到期日期。
- 保证金/押金：在同一条款文本中出现保证金、押金或质保金，但未检出返还表述时提示核对退还条件；其他条款里的“退还”字样不会替代本条款的返还约定。
- 违约责任：检出违约金但未识别计算方式、金额或上限时提示核对。
- 自动续约：在自动续约条款本身未识别提前通知天数时提示核对；合同其他位置的普通通知期限不会自动视为续约通知期限。
- 条款关键词：检查付款结算、交付验收、违约责任、争议解决、发票、质保/保证金关键词。

**重要边界：** 这些是可解释的文本筛查规则，不是法律结论。关键词未检出不等于条款缺失；付款比例只计算可识别的付款句段，复杂表格、跨页条款、中文大写金额、扫描件或 OCR 内容可能无法准确解析。金额口径、补充协议、例外条款及实际履约情况必须人工核对。规则按提取文本中的条款行进行筛查，跨段、跨页或表格拆分的关联内容可能产生额外提示。风险等级仅用于安排复核优先级，不代替律师审查，也不会自动修改正式合同台账。

**支持边界：** 不调用 OCR、AI、VPN、云服务或外部 API。扫描件/图片型 PDF 若没有可复制文字会明确提示，不会伪造识别结果。加密 PDF 需先在本机解密。单文件上限 50 MiB、PDF 上限 500 页、提取文本上限 200 万字符。批量文件先全部解析，成功后才原子写出草稿；其中一份失败不会覆盖已有草稿。

## 人工复核结论与历史留档（新增）

“批量识别合同文件”生成的草稿 CSV 增加了来源文件 SHA256、风险明细 SHA256，以及“人工结论、复核人、复核备注”三列。请只填写人工复核列，不要修改来源指纹、规则版本或风险明细；如需修改合同原文，应重新识别并生成新草稿。

人工结论只允许：
- **已复核（无待办）**：已对照签署原件完成本轮核对；如果存在风险命中，必须填写备注说明核对依据或处理结果；
- **需补充材料**：需要补充附件、补充协议或履约材料，必须填写复核备注；
- **暂缓处理**：暂时无法判断或等待业务确认，必须填写复核备注。

填写后点击“导入复核结果”。软件会校验来源 SHA256、风险明细 SHA256、规则版本、命中数量、复核人和结论；任一行无效时整批拒绝。完全相同的复核内容不会重复导入。导入后会保留复核时间、复核人、结论、备注、原始文件指纹、规则版本及风险明细，供“复核记录”查看，也可用“导出复核记录”生成 CSV。重新复核会追加一条历史，不覆盖旧记录。在“复核记录”窗口选中一条记录后，可点击“对比上一版风险变化”，查看新增、不再命中和保持不变的风险项。对比只匹配同一合同编号、同一规则版本下不同 SHA256 的文件版本；如果合同编号未识别、没有更早版本或规则版本不同，软件会说明无法直接比较。此功能比较的是风险命中清单，不是合同全文逐字差异。

SHA256 只用于识别文件内容和发现草稿字段被意外改动；它不是数字签名、可信时间戳，也不能证明文件来源或法律真实性。生成的合同识别草稿、合同 CSV、履约节点 CSV 和复核历史 CSV 均会对公式型文本加安全前缀，避免 Excel/WPS 将其当作公式执行。复核结论是内部工作状态，不代表合同合法、有效或风险已被法律消除。

## 履约节点 CSV
“节点导出”导出全部履约节点；“节点导入”采用追加模式。CSV 必须包含完整字段表头并使用 UTF-8（带 BOM 也可）。节点编号不能重复，合同编号必须已存在；任何一行格式错误或引用不存在的合同，整批拒绝，不会只导入部分记录。

## 合同 CSV
合同 CSV 使用 UTF-8（带 BOM 也可），必须包含全部合同字段。导入采用追加模式，不覆盖已有合同；如有重复合同编号、日期错误、金额无效或缺少字段，整批拒绝。导出可按当前搜索和提醒筛选结果导出。

## 操作记录
“操作记录”显示合同新增/修改/删除、履约节点新增/修改/完成/删除、CSV 导入和合同复核结果导入等记录。人工复核历史独立保存在本机 contract_reviews.json，可查看和导出，不会上传。

## 备份与恢复
v3 新版备份包含合同、履约节点、操作记录和人工复核历史，恢复前会先校验数据格式、版本、节点字段、重复编号、合同关联、复核结论及 SHA256。v1/v2 旧备份仍可恢复；旧版本不含人工复核历史，恢复旧备份时复核历史会清空。恢复会替换当前数据，请先备份现有文件。旧版 v1 备份仍可恢复合同主表，但不含履约节点和操作记录；从旧版备份恢复时，当前履约节点和日志会清空。

## 使用边界与隐私
批量识别模块会在本机提取可搜索 PDF/DOCX/TXT/MD 的文字并生成待人工复核草稿，不会自动写入正式台账；软件不调用 AI，不自动发送短信/微信/邮件，也不上传合同资料。请由使用者对照合同原文复核字段、履约节点和风险提示。重要合同应由有资质的专业人士审阅。
