# 合同台账与到期提醒助手｜用户说明书

## 产品用途
用于小微企业、工作室、门店和个人经营者登记合同信息，查看合同到期日期，并按设定的提前天数筛选续约提醒。软件完全本地运行，无需 VPN、ChatGPT、云端 AI 或外部 API。

## 首次使用与数据位置
双击“合同台账与到期提醒助手.exe”。首次启动按提示提供设备码并完成授权。合同数据自动保存在：
`%LOCALAPPDATA%\MainlandBusinessTools\contracts.json`
建议定期使用软件内的“备份”功能，并把备份复制到 U 盘或其他安全位置。

## 新增合同
必填合同编号、合同名称、签订日期、生效日期和到期日期。日期统一使用 YYYY-MM-DD。生效日期和签订日期不得晚于到期日期。合同金额按人民币等货币数值记录，精确到分；续约提醒提前天数默认 30 天，可设置 0–3650 天。

## 到期提醒
- “正常”：距离到期日仍大于提前提醒天数。
- “即将到期”：剩余天数小于或等于提前提醒天数。
- “已逾期”：到期日期早于今天。
- “已续约”或“已终止”：不再显示到期提醒。
勾选“只看需要提醒”可筛出即将到期和已逾期合同。提醒是软件内的本地筛选，不会在程序关闭时发送短信、微信或系统推送。

## CSV 导入与导出
CSV 使用 UTF-8（带 BOM 也可），必须包含全部字段表头。导入采用追加模式，不覆盖已有合同；如有重复合同编号、日期格式错误、金额无效或缺字段，整批拒绝导入。导出可按当前搜索和提醒筛选结果导出。

## 备份与恢复
“备份”生成带格式和版本标记的 JSON 文件；“恢复”会替换当前合同台账，并在执行前要求确认。恢复前请先备份当前数据。不要手动修改程序文件夹中的内容。

## 使用边界
本软件是合同信息台账和到期日期提醒工具，不提供法律意见，不自动判断合同条款效力，也不连接邮箱、微信或短信服务。请自行核实合同原件和重要期限。
