# 食品批次与保质期追踪助手｜用户说明书

## 1. 产品用途

面向便利店、食品小店、烘焙店、零食店及小型餐饮门店，按“商品 + 批次”管理入库日期、生产日期、到期日期、供应商、库位和剩余数量。

本工具重点不是简单记录库存，而是提供：

- **FEFO 先到期先出库**：同一商品可跨多个批次自动分配，优先扣减最早到期批次。
- **效期分层预警**：已过期、3 日内、7 日内、30 日内和正常库存分层显示。
- **批次追溯**：每次入库、出库、调整、作废均形成流水，能按批次查看去向和原因。
- **库存调整留痕**：编辑批次资料不会直接改数量；数量变化必须通过调整或出库操作。
- 本地持久化、CSV 批量导入/导出、库存流水导出及完整 JSON 备份/恢复。

软件只在本机运行，不依赖 VPN、ChatGPT、外部 AI、OCR 或云服务。

## 2. 首次使用

1. 双击 `MainlandFoodBatchExpiryAssistant.exe`。
2. 首次启动显示本机设备码；由卖家为该产品签发独立授权文件后才能进入。
3. 数据默认保存在 `%LOCALAPPDATA%\MainlandBusinessTools\food_batches.json`。
4. 建议先建立一个测试商品和两个不同到期日期的批次，验证效期排序与出库分配，再录入真实库存。

## 3. 新增批次

填写批次编号、商品编码、商品名称、供应商、生产日期、到期日期、入库日期、数量、单位、成本单价和库位。

- 批次编号必须唯一；同一商品允许存在多个不同批次。
- 日期统一使用 `YYYY-MM-DD`。
- 生产日期不能晚于入库日期或到期日期；入库日期不能晚于到期日期。
- 数量和成本单价必须为非负数字；批次初始数量大于零时会自动记录入库流水。
- 若商品无生产日期，可留空；到期日期和入库日期必填。

## 4. FEFO 按效期优先出库

1. 点击“按效期出库”，输入商品编码、出库数量、去向和原因。
2. 软件只选择尚未过期且库存大于零的批次。
3. 系统按到期日期、入库日期、批次编号排序，先扣减最早到期批次；若单批数量不足，会自动跨批次分配。
4. 如果未过期库存总量不足，整笔出库会被拒绝，不会只扣一部分。
5. 完成后每个实际扣减批次都会生成独立出库流水。

FEFO 仅是库存分配建议，门店仍须按商品标签、储存条件和食品安全要求人工复核。

## 5. 效期预警与批次追溯

- 已过期：到期日期早于今天；不会参与 FEFO 出库。
- 3 日内到期：剩余 0–3 天。
- 7 日内到期：剩余 4–7 天。
- 30 日内到期：剩余 8–30 天。
- 正常：剩余超过 30 天。
- 已清零：当前数量为 0。

选择批次后点击“批次追溯”，可查看其入库、出库、调整和作废流水。流水记录批次、商品、类型、数量、时间、去向和原因。

## 6. 库存调整与作废

- “库存调整”必须选择增加/减少并填写原因；减少数量不能超过当前库存。
- “编辑批次”仅编辑商品、供应商、日期、库位等资料，当前数量只读，避免绕过流水。
- “作废批次”会把剩余数量归零并记录作废流水，不会物理删除历史记录。

## 7. CSV 导入与导出

- 批次 CSV 必须包含全部字段；可先点击“导出批次 CSV”，用导出文件确认字段名称和顺序，再按相同列结构准备导入文件。
- 导入前会校验日期、数字和批次编号；发现重复批次、缺列或非法值时整批拒绝，不会部分导入。
- 成功导入的批次会生成“CSV 期初批次导入”流水。
- “导出批次 CSV”导出当前批次资料；“导出库存流水”单独导出追溯记录。
- 为防止 Excel/WPS 把文本当公式执行，导出时会给去除前导空白后以 `=`、`+`、`-` 或 `@` 开头的单元格添加英文单引号；这是安全处理，不代表原始业务数据被改写。

## 8. 备份与恢复

- “备份”会保存批次、当前数量和全部库存流水到 JSON。
- “恢复备份”会替换当前批次与流水；恢复前请先做一次备份。
- 格式、版本、批次编号、流水编号及流水关联校验全部通过后才写入；错误备份不会覆盖现有数据。
- 建议每天营业结束后备份到另一块磁盘或 U 盘。

## 9. 注意事项与限制

- 本软件不是食品安全监管系统，不替代进货查验、标签核对、温度记录、召回制度或监管要求。
- 软件不会自动连接扫码枪、电子秤、收银系统或供应商平台；CSV 可作为批量数据交换入口。
- 扫描件 OCR、自动识别生产日期、自动短信/微信提醒不在本版范围内。
- 系统日期不准确会影响效期剩余天数；请保持 Windows 日期正确。
- 任何临期/过期处置均应按商品标签、储存条件和当地法规执行。

## 10. 常见问题

**同一个商品能有多个批次吗？** 可以，只要批次编号不同，商品编码可以重复。

**过期批次能否出库？** 不可以。过期库存会显示“已过期”，并被 FEFO 自动排除。

**为什么不能在编辑窗口直接修改数量？** 为保留库存审计记录，数量变化必须使用“库存调整”或“按效期出库”。

**导入 CSV 后数量流水在哪里？** 初始数量会生成“CSV 期初批次导入”入库流水，可通过批次追溯或导出库存流水查看。

**可以换电脑吗？** 可在旧电脑备份 JSON，再在新电脑恢复；授权仍需按新设备码单独处理。
