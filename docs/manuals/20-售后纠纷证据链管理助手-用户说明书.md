# 售后纠纷证据链管理助手｜用户说明书

## 一、适用场景

用于闲鱼及其他交易平台的售后纠纷记录、响应期限跟踪和证据文件归档。适合个人卖家、小店客服和需要整理订单争议材料的经营者。

本工具不连接闲鱼或其他平台，不自动抓取聊天、订单或退款数据，也不代替平台申诉、客服沟通或法律意见。请由用户自行从平台导出或保存原始资料，再选择文件归档。

## 二、核心能力

- 按案件编号建立售后案件，记录平台、订单号、商品、纠纷类型、购买日期、响应截止日期、退款/补偿金额、负责人和处理状态。
- 按响应截止日期排序，显示逾期、今日截止、3 日内截止和已结束状态。
- 将聊天记录、订单截图、物流凭证、付款凭证等文件复制到本地证据目录；记录原始文件名、文件大小、添加时间和 SHA256。
- 案件创建、字段更新、状态变更和添加证据都会追加事件记录，并通过 SHA256 前序哈希形成连续事件链。
- 一键导出单案件证据包，包含案件摘要、该案件事件 CSV、该案件事件链引用、证据索引、已归档文件和 ZIP 文件清单。
- 支持案件 CSV 导入/导出、证据索引导出、全量 ZIP 备份与恢复，以及本地事件链和证据文件完整性校验。

## 三、首次使用

1. 双击 `MainlandAfterSalesEvidenceAssistant.exe`。
2. 首次运行会显示设备码；按卖家提供的授权文件说明完成授权。
3. 点击“新建案件”，案件编号建议使用自己可持续追踪的唯一编号，例如 `XY-2026-0001`。
4. 填写平台、订单编号、商品名称、纠纷类型和响应截止日期。金额必须为非负数，日期使用 `YYYY-MM-DD`。
5. 保存案件后，在列表中选中案件，点击“添加证据”。
6. 选择本机原始证据文件并填写说明。程序会复制文件，不会修改原始文件；单个文件最大 100 MiB。
7. 需要提交或交接材料时，选择案件并点击“案件证据包”，导出 ZIP。

建议保留平台原始导出文件和未经编辑的截图；归档副本用于整理与校验，不应替代原始资料。

## 四、事件链与完整性校验

每次新增案件、更新案件、变更状态或添加证据时，程序会追加事件，并把前一条事件哈希写入下一条记录。点击“校验完整性”可检查：

- 事件序号是否连续；
- 每条事件的前序哈希和事件哈希是否匹配；
- 证据文件是否存在；
- 证据文件大小和 SHA256 是否与登记记录一致。

哈希链用于发现普通文件修改、缺失或意外损坏，不是数字签名或可信时间戳。拥有本地文件写权限的人仍可能重写整份数据和哈希链；哈希也不能证明证据由谁制作、何时制作、是否完整或是否被平台/法院采信。请保留平台原始记录，不要把本工具的校验结果宣传为“司法鉴定”或“法律证据认证”。

案件证据包只包含所选案件的事件，不会把其他案件的买家、订单或事件详情一并导出。`event-chain.json` 会保留所选案件事件的原始序号和前序哈希，并注明它是全局事件链的案件范围摘录；要验证完整全局链，请在原电脑的本地数据中执行完整性校验。

## 五、CSV 与数据安全

- CSV 使用 UTF-8 BOM，适合常见表格软件打开。
- 案件 CSV 导入必须包含全部字段；重复案件编号、缺失字段、非法金额或日期会导致整批拒绝，不会只导入部分行。
- 导出 CSV 时，可能被表格软件解释为公式的文本会加安全前缀；正常 CSV 导入会还原该前缀。
- 已关联证据的案件编号不可修改，以免破坏案件与证据的关联。
- 证据文件和案件数据仅保存在本机，不上传云端。

## 六、备份与恢复

1. 定期点击“备份”，保存 ZIP 文件到其他磁盘或安全位置。
2. 备份包含案件、证据索引、完整事件链、证据文件及逐文件 SHA256 清单。
3. 恢复前请先为当前数据另做备份。
4. 点击“恢复”并选择 ZIP；程序会校验 ZIP CRC、清单、文件大小、SHA256、案件关联和事件链。
5. 确认恢复会替换当前案件数据和证据目录。损坏、路径越界、清单不匹配或超过 1 GiB 解压大小的备份会被拒绝。

## 七、本地文件位置

默认数据目录：

- `%LOCALAPPDATA%\MainlandBusinessTools\after_sales_cases.json`
- `%LOCALAPPDATA%\MainlandBusinessTools\after_sales_evidence\`

请勿手动移动或重命名证据目录中的文件；否则完整性校验会报告文件缺失。

## 八、限制与免责声明

- 单个证据文件上限 100 MiB；备份 ZIP 文件和解压后内容上限 1 GiB。
- 软件不会自动登录平台、抓取聊天、发送申诉、联系买家或替用户作出退款决定。
- SHA256 只能校验文件内容是否与登记时一致，不能证明来源、形成时间、真实性或法律效力。
- 本软件提供记录与整理辅助，不构成法律意见；涉及高额损失或复杂争议，请向平台或专业人士咨询。

## 九、运行环境

Windows 10/11；无需安装 Python；本地运行，不依赖 VPN、ChatGPT、外部 AI 或云端 API。
