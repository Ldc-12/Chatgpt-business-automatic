# 设备维保巡检与保养计划助手｜用户说明书

## 一、产品用途

适合餐饮门店、便利店、小型工厂、物业和服务门店管理空调、冷藏柜、厨房设备、水泵、办公设备等资产。它把设备台账、保养计划、维保记录、验收状态、停机时长和费用汇总放在同一套本地数据中。

软件不连接设备、不远程诊断、不自动下达维修指令，也不替代具备资质的专业人员或法定检验。内置周期只是可调整的内部提醒默认值，不代表法规或厂家强制周期。

## 二、首次使用

1. 解压后双击“设备维保巡检与保养计划助手.exe”。
2. 首次启动显示设备码；购买授权后，将“设备维保巡检与保养计划助手.json”放入：
   %LOCALAPPDATA%\MainlandBusinessTools\licenses\
3. 数据默认保存在：
   %LOCALAPPDATA%\MainlandBusinessTools\equipment_maintenance.json
4. 建议先录入一台测试设备，完成一次维保记录、导出和备份恢复测试，再录入正式资产。

## 三、设备台账

点击“新增设备”，填写设备编号、名称、类别、安装位置、负责人、启用日期、保修到期日和保养周期。

内置类别及可调整的初始周期：

| 类别 | 默认周期 |
|---|---:|
| 冷藏冷冻 | 30 天 |
| 空调通风 | 90 天 |
| 厨房设备 | 90 天 |
| 水泵机电 | 90 天 |
| 办公设备 | 180 天 |
| 消防设施 | 180 天 |
| 其他 | 90 天 |

这些数字仅为软件初始提醒值。请根据设备说明书、服务合同、设备实际工况和当地适用要求自行确认并调整。消防、电梯、压力容器等依法需要专业检测或维护的设备，仍须按规定委托合格机构处理。

## 四、维保记录与风险提示

选中设备后点击“登记维保”，记录维护日期、类型、内容、服务商/人员、停机时长、费用及验收状态。保存后自动更新最近维保日期，并按设备保养周期计算下次提醒日期。

- 已验收：设备状态恢复为“正常”。
- 待验收：风险清单提示仍有待验收记录。
- 不通过：设备状态改为“待检修”，在完成复核前保持高风险提示。
- 设备“维修中”或“待检修”会显示高风险。
- 已逾期保养显示高风险；14 天内到期显示中风险。
- 保修 30 天内到期或已过保修期会单独提示。
- 停机时长和费用按维保记录累计统计。

风险等级是内部管理提醒，不是设备安全鉴定。请结合现场检查结果处理，不要仅凭软件提示决定设备能否继续运行。

## 五、搜索、筛选与报表

- 可按设备编号、名称、类别、位置、负责人、状态和风险说明搜索。
- 可按设备类别和设备状态筛选。
- “导出设备 CSV”导出当前筛选设备。
- “查看维保历史”打开所选设备的维保流水，并显示该设备的费用与停机时长汇总。
- “导出维保记录”导出完整维保历史。
- “导出风险清单”导出风险等级、说明、逾期天数和维护记录数。
- 导出使用 UTF-8 BOM，兼容 Excel/WPS；以 =、+、-、@ 等开头的文本会增加安全前缀，避免被表格软件当作公式执行。


## 六、维保成本分析

点击主窗口“维保成本分析”，可按开始日期和结束日期筛选维保记录（日期边界均包含；留空表示不限制该端）。分析页分为三个视图：

- **按设备**：列出每台设备的维保次数、累计维保费用、费用占比、单次平均费用、累计停机时长和最近维保日期，并按费用从高到低排序。
- **按服务商/人员**：汇总每家服务商/人员的记录数、涉及设备数、累计费用、费用占比和停机时长，便于核对供应商支出。
- **按月份**：按维护日期归集每月维保次数、费用和停机时长，观察支出变化。

每个视图都可以单独导出 CSV，导出文件使用 UTF-8 BOM 和公式注入防护。分析只统计软件中已经登记的“费用(元)”和“停机时长(小时)”，不包含设备采购价、能源消耗、人工工资或停产损失，因此不是完整的设备全生命周期成本，也不能直接用于会计入账或供应商质量定责。

## 七、CSV 导入规则

设备 CSV 必须包含全部规定字段，不能增加或重复列名。软件会检查日期、类别、周期、状态和重复设备编号；采用追加模式，不覆盖现有设备。文件最大 25 MiB，最多 50,000 条。任一行不合法或与现有编号冲突时整批拒绝，原数据保持不变。

## 八、备份与恢复

- 点击“备份”可将设备台账和完整维保历史保存为一个 JSON 文件。
- 建议每周备份，并将备份复制到 U 盘或其他安全位置。
- 点击“恢复备份”会替换当前设备和维保记录，软件会再次确认；恢复前建议先备份当前数据。
- 有维保历史的设备不允许直接删除或更改设备编号；如设备退役，请把状态设为“停用”，保留历史记录。

## 九、注意事项

- 软件本地运行，不需要 VPN、ChatGPT、外部 AI 或云端服务。
- 数据只保存在当前 Windows 用户本机，不会自动同步到其他电脑。
- 不会自动发送短信、微信或系统通知；提醒在软件列表和风险清单中显示。
- 请保护设备联系人、供应商和维保费用等业务资料，定期备份。
