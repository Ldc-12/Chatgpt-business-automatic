# 供应商对账与应付账龄管理助手 用户说明书

## 1. 软件用途
用于小微企业、零售门店和采购人员管理供应商应付单据、分笔付款、到期提醒、账龄分析和供应商对账单差异。软件在本机运行，不连接银行、支付平台、ERP 或供应商系统。

## 2. 首次使用
1. 双击 \`MainlandSupplierAPAging.exe\`。
2. 在“新增应付单据”中录入供应商编号、名称、发票号、单据日期、到期日期、金额和备注。
3. 建议供应商编号固定使用企业内部编码；同一供应商的发票号不能重复。
4. 数据默认保存在 \`%LOCALAPPDATA%/MainlandBusinessTools/supplier_ap.json\`。

## 3. 付款登记
- 在主表选择一张应付单据，点击“记录付款”。
- 每次付款都关联到选中的单据，填写金额、付款日期、凭证号和备注。
- 软件会检查付款日期不早于单据日期，并拒绝超过该单据未付余额的付款。
- “付款记录”可查看所选单据的分笔付款。已有付款记录的单据不能直接删除，以免丢失付款关联。

## 4. 账龄和到期清单
账龄按“统计日期 - 到期日期”计算，仅对未付余额大于 0 的单据统计。历史统计只累计付款日期不晚于统计日期的付款；统计日期之后发生的付款不会改变此前日期的历史账龄。

账龄区间如下：
- 未到期：统计日期不晚于到期日期
- 逾期 1–30 天
- 逾期 31–60 天
- 逾期 61–90 天
- 逾期 90 天以上

点击“账龄报表”导出逐张单据的金额、已付金额、未付金额、逾期天数和账龄区间；“供应商汇总”按供应商汇总各账龄区间余额。统计日期由使用者输入，不会自动读取系统外部数据。

## 5. 供应商对账单核对
对账单 CSV 必须使用 UTF-8 或 UTF-8 BOM，并严格使用以下表头：

\`供应商编号,供应商名称,发票号,单据日期,金额\`

点击“对账单核对”选择文件，软件会比较供应商编号、发票号、日期和金额，并列出：
- 本地缺少单据
- 对账单缺少本地单据（仅比较对账单日期范围内、已出现在对账单的供应商）
- 供应商名称不一致
- 单据日期不一致
- 金额不一致

核对过程只读取文件，不会自动新增、修改或删除本地单据。发现差异后可点击“导出差异”留档。空对账单、重复供应商发票号、错误表头或无效金额会被拒绝，不会被当作“无差异”。

## 6. CSV 导入与导出
- 应付单据导入表头必须与软件导出的单据 CSV 完全一致。
- 导入前会校验所有行、重复单据编号和重复供应商发票号；全部通过后一次性写入，失败时不导入部分数据。
- 单据导出、账龄报表和对账差异均为 UTF-8 BOM CSV，便于 Excel/WPS 打开。
- 文本字段会进行公式前缀防护。若原始文本以 \`=\`、\`+\`、\`-\` 或 \`@\` 开头，导出时会增加单引号，避免表格软件将其当作公式执行。

## 7. 备份与恢复
“备份”生成包含应付单据和付款记录的 JSON，并带 SHA256 完整性校验；单文件上限 100 MiB。恢复会替换当前数据，恢复前建议先备份当前文件。校验失败不会覆盖当前数据。

## 8. 数据与隐私
软件只在本机保存数据，不要求 VPN、ChatGPT、外部 AI、云账户、网络服务或银行登录。请妥善保护 Windows 用户账户和备份文件。软件不会自动付款、自动发送催款信息或连接供应商系统。

## 9. 适用限制
账龄与对账差异是根据本地录入数据和导入的供应商对账单进行的内部管理辅助，不构成会计、审计、税务或法律意见。付款分配由用户选择单据后手工登记；软件不会推断银行流水对应哪张发票。上线前请核对企业实际账期和对账口径。
