# 装修材料用量与预算核算助手 用户说明书

## 1. 软件用途

面向装修施工队、设计/监理人员及有装修采购需求的业主，按项目、房间和材料建立本地材料清单，计算净用量、损耗后的计划用量、整包装采购数量和预算；录入实际采购后可比较预算与实际金额。

软件提供瓷砖片数/整箱数和乳胶漆升数的独立计算器。所有计算参数均可由使用者按现场尺寸、产品包装和厂家技术资料调整，不会自动读取 CAD 图纸或识别施工图。

## 2. 首次使用

1. 双击 `MainlandRenovationMaterialsAssistant.exe`。
2. 每条材料记录填写唯一记录编号、项目编号/名称、房间/区域、材料编码/名称、类别、计量单位、净用量、损耗率、包装规格和单价。
3. 同一项目编号必须始终使用同一项目名称；不同房间可以使用相同材料编码。
4. 数据默认保存在 `%LOCALAPPDATA%/MainlandBusinessTools/renovation_materials.json`。

## 3. 用量和预算规则

- 计划用量 = 净用量 × (1 + 损耗率)。
- 建议采购包装数 = 向上取整(计划用量 ÷ 包装规格)。
- 建议采购量 = 建议采购包装数 × 包装规格。
- 预算金额 = 建议采购量 × 单价。

包装规格和单价必须使用同一计量单位。例如单价按每平方米计价时，包装规格也应填写每包折算的平方米数；若按每箱计价，请先将单价换算成每片或每平方米后再录入，避免单位混用。

## 4. 数值输入范围

为避免异常大数、超长数字文本或精度过低的输入造成计算中断，所有数值字段均限制为绝对值不超过 1,000,000,000，数字文本最多 64 个字符。净用量、包装规格和实际采购量至少精确到 0.001；单价和实际金额至少精确到人民币 0.01 元。超过范围或舍入后变成零的正数会被拒绝，原台账不会因此被覆盖。

## 5. 专项计算器

### 瓷砖

输入铺贴净面积、瓷砖长宽（毫米）、损耗率和每箱片数。软件先按单片面积计算理论片数，再向上取整到整片和整箱。异形铺贴、斜铺、复杂拼花、墙地对缝、门洞/柱体、破损率及不同批次色差需现场另行核算。

### 乳胶漆

输入涂刷面积、遍数、每升理论涂布面积和损耗率，结果按 0.1 L 向上取整。涂布率应以具体产品说明书、基层吸收情况、施工工具和实际遍数为准；底漆与面漆应分开建立材料行。

## 6. 实际采购与预算差异

录入实际采购量和实际金额后，列表及项目预算汇总会显示实际金额减预算金额的差额。正数表示超预算，负数表示低于预算。实际金额为空时不会假设为零，也不会将未采购材料计入已发生费用。

## 7. CSV 导入与导出

- CSV 使用 UTF-8 BOM，表头必须与软件导出的 16 个字段和顺序完全一致。
- 导入前会逐行校验数字、单位、类别、记录编号及项目名称一致性；重复记录编号或任意坏行都会导致整批拒绝，不会部分写入。
- 导出时文本字段以单引号防护以 `=`、`+`、`-`、`@` 开头的表格公式内容。
- 建议先导出空白模板，再按模板整理数据。

## 8. 备份与恢复

“备份”生成包含全部材料行的 JSON 文件，并对材料数据计算 SHA256。恢复前会先校验格式、版本、SHA256、字段和项目关系；任何校验失败都不会替换当前数据。恢复会整体替换现有记录，建议先备份当前数据。

## 9. 数据与隐私

软件在本机保存数据，不依赖 VPN、ChatGPT、外部 AI、云账户或网络服务。请妥善保管 Windows 账户和备份文件。项目地址、客户姓名及供应商资料应按最小必要原则录入。

## 10. 重要限制

本工具是材料用量和预算辅助，不是工程量清单审价、造价鉴定、施工图深化或质量验收意见。计算结果取决于用户输入尺寸、损耗率、包装规格和产品涂布率；现场复尺、基层条件、施工规范、合同计价口径及供应商报价仍须人工确认。软件不保证材料一定够用，也不代替专业施工人员复核。
