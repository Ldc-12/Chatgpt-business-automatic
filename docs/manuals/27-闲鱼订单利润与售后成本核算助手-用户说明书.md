# 闲鱼订单利润与售后成本核算助手 用户说明书

## 1. 软件用途

面向闲鱼个人卖家、小型二手商家和多 SKU 经营者，按订单记录实收、商品成本、包装、运费、平台费用、推广费用、退款、补偿和退货回收金额。软件可计算订单净利润、净利率、月度利润和 SKU 汇总，并提供保本售价计算器。

软件只在本机处理用户手工录入或 CSV 导入的数据，不连接闲鱼账号、不抓取订单、不自动发布商品、不代替用户收付款。

## 2. 首次使用

1. 双击 `MainlandXianyuProfitAssistant.exe`。
2. 输入唯一记录编号、订单编号、成交日期、商品/SKU、买家实付金额和商品成本。
3. 可按实际情况填写包装成本、发货运费、平台费率/固定费用、实际平台费用、推广费、退款、售后补偿、退货运费和售后回收金额。
4. 同一个订单可以有多条 SKU 明细，但每条记录编号必须唯一。
5. 数据默认保存在 `%LOCALAPPDATA%/MainlandBusinessTools/xianyu_order_profit.json`。

## 3. 利润计算口径

- 订单净收入 = 买家实付金额 − 售后退款。
- 估算平台费用 = 买家实付金额 × 本单平台费率 + 本单平台固定费用。
- 如果填写“实际平台费用”，则优先使用实际值；留空时才使用估算值。
- 成本支出 = 商品成本 + 包装成本 + 发货运费 + 平台费用 + 推广费用 + 售后补偿 + 退货运费。
- 订单净利润 = 订单净收入 − 成本支出 + 售后回收金额。
- 净利率 = 订单净利润 ÷ 订单净收入 × 100%。

平台费率和固定费用不是闲鱼官方费率，也不会自动套用平台政策。不同订单可能因类目、交易方式、活动或规则变化而不同，请按本单实际费用填写；有账单时优先填“实际平台费用”。退款超过买家实付金额的记录会被拒绝。

## 4. 售后记录口径

“售后退款”填写已退给买家的金额；“售后补偿”填写退款之外另行补偿的金额；“退货运费”填写卖家承担的退货物流费用；“售后回收金额”填写退回商品经检查后可继续销售或利用的回收价值。回收金额不会自动判断商品是否可二次销售，应由卖家自行核实。

## 5. 保本售价

输入平台费前成本、平台费率和固定费用，软件按：

`保本售价 = (平台费前成本 + 平台固定费用) ÷ (1 − 平台费率)`

计算，并按人民币分向上取整。结果不含利润目标、议价空间、税费或未录入的风险成本。

## 6. 月度与 SKU 汇总

- 月度汇总按成交日期统计订单数、售后订单数、实收、退款、净收入、成本支出、回收金额和净利润。
- 月度“订单数”和“售后订单数”均按订单编号去重。同一订单包含多个 SKU 明细时只计一笔；只要该订单任一明细处于售后中/已退款，或存在退款金额，就计为一笔售后订单。
- SKU 汇总按商品/SKU 统计订单数、净收入和净利润；同一订单同一 SKU 有多条明细时，SKU 订单数只计一笔，金额仍按每条明细累加。
- 同一订单多条 SKU 明细会分别计入金额；请按成本分摊规则填写，避免重复计算整单运费或推广费用。

## 7. CSV 导入与导出

- CSV 使用 UTF-8 BOM，表头和字段顺序必须与软件导出模板一致。
- 导入会校验日期、状态、金额、费率、退款上限和唯一记录编号；任意坏行或重复记录编号都会整批拒绝，不会部分写入。
- 导出时文本字段以单引号防护以 `=`、`+`、`-`、`@` 开头的表格公式内容。
- 建议先导出空白模板，再按模板整理订单。

## 8. 备份与恢复

“备份”生成包含全部订单的 JSON 文件，并计算订单数据 SHA256。恢复前会校验格式、版本、SHA256、订单字段和记录编号；任何校验失败都不会替换当前数据。恢复会整体替换现有订单，建议先备份当前数据。

## 9. 数据与隐私

软件在本机保存数据，不依赖 VPN、ChatGPT、外部 AI、云账户或网络服务。买家昵称等个人信息建议只记录必要内容，并妥善保管 Windows 账户和备份文件。

## 10. 重要限制

本工具不是闲鱼官方工具，不代表平台规则、收费政策或交易保障意见。平台费用需卖家自行核对；软件不读取平台账单、不自动同步订单、不执行交易。利润结果取决于用户录入的成本、费用、退款和回收金额，不能替代税务、会计或经营决策建议。
