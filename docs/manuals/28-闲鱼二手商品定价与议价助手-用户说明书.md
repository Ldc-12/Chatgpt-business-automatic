# 闲鱼二手商品定价与议价助手 用户说明书

## 1. 软件用途

面向闲鱼个人卖家、二手数码商家和多品类闲置卖家。软件根据商品品类、购入时间、成色、配件/瑕疵扣减、整备费用、包装运费、售后预留、平台费用和目标利润，计算折旧模型估值、建议标价与最低接受价。

它用于把卖家自己的成本和手工收集的同类成交参考整理成可解释的定价记录，不连接闲鱼账号，不抓取商品或成交数据，不自动发布商品、聊天或收付款。

## 2. 首次使用

1. 双击 `MainlandXianyuUsedPricingAssistant.exe`。
2. 新增商品，填写唯一商品编号、名称、品类、购入日期、原价、购入成本和成色。
3. 按实际情况填写配件/瑕疵扣减、整备费用、包装运费、售后预留、平台费率、固定费用和目标利润。
4. 如果你已手工收集同型号、同成色的可比成交价，可填写“同类成交中位价”；没有可靠样本时留空。
5. 数据默认保存在 `%LOCALAPPDATA%/MainlandBusinessTools/xianyu_used_pricing.json`。

## 3. 版本化估值规则

- 规则版本：`XY-USED-PRICE-2026.11`。
- 内置品类：手机数码、电脑办公、家用电器、家具家居、运动户外、母婴用品、服饰鞋包、工具设备和其他。
- 折旧系数按 0、6、12、24、36、60 个月分段；不同品类使用不同系数。
- 成色系数：全新未拆封 1.00、近全新 0.93、9 成新 0.86、8 成新 0.75、7 成新 0.62、明显瑕疵 0.45。
- 折旧模型估值 = 原价 × 品类折旧系数 × 成色系数 − 配件/瑕疵扣减，最低为 0。
- 填写同类成交中位价后，估值基准 = 折旧模型估值 × 40% + 手工录入中位价 × 60%；未填写时只使用折旧模型。
- 以上系数是可解释的初始规则库，不是闲鱼官方估价、实时行情或保证成交价。不同品牌、型号、地区、保修、版本、供需和交易风险会显著影响价格。

## 4. 最低接受价与建议标价

- 固定成本 = 购入成本 + 整备费用 + 包装运费 + 售后预留 + 平台固定费用。
- 最低接受价 = (固定成本 + 目标利润) ÷ (1 − 平台费率)，按人民币分向上取整。
- 建议标价 = max(估值基准, 最低接受价) × (1 + 议价空间)，再向上取整到整元。
- “最低接受价”是内部谈价底线，复制的公开上架文案不会包含它。
- 平台费率与固定费用由卖家按实际账单填写，软件不声称掌握闲鱼当前收费政策。若实际平台费用不同，应更新费率或固定费用后重新计算。

## 5. 定价分析与上架文案

选中商品后使用“定价分析”查看规则版本、使用月数、折旧/成色系数、估值基准、建议标价、最低接受价和预计利润。“复制上架文案”只生成基础标题、品类、成色和参考标价；发布前必须自行补充真实配件、瑕疵、保修、发货和售后信息，不能把模板描述当成商品事实。

## 6. CSV 导入与导出

- CSV 使用 UTF-8 BOM，表头和字段顺序必须与软件导出的模板完全一致。
- 导入会校验品类、成色、日期、金额、费率、议价空间和唯一商品编号；任意坏行或重复编号都会整批拒绝，不会部分写入。
- 单次最多导入 100,000 条，CSV 文件上限 100 MiB。
- 导出时文本字段以单引号防护以 `=`、`+`、`-`、`@` 开头的表格公式内容。

## 7. 备份与恢复

“备份”生成 JSON 文件并计算商品数据 SHA256。恢复前校验格式、版本、SHA256、商品字段和唯一编号；校验失败不会替换当前台账。恢复会整体替换现有记录，建议先备份当前数据。

## 8. 数据与隐私

软件只在本机处理手工录入或 CSV 数据，不依赖 VPN、ChatGPT、外部 AI、云账户或网络服务。数据默认保存在当前 Windows 用户的本地应用数据目录。请妥善保管 Windows 账户和备份文件。

## 9. 重要限制

估值规则是透明的内部参考系数，用户手工录入的同类成交中位价也可能存在样本偏差；本工具不采集实时行情、不承诺成交、不提供税务或法律意见。卖家仍须核实商品真伪、权属、成色、配件、维修史、保修和适用交易规则。
