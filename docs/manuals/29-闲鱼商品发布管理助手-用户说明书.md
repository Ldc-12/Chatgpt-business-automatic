# 闲鱼商品发布管理助手｜用户说明书

## 一、用途

本工具用于离线维护闲鱼卖家的商品发布台账，适合同时管理多件二手商品的个人卖家和小型商家。它不登录闲鱼、不读取账号、不抓取商品或成交数据，也不会自动发布、刷新或联系买家。

## 二、核心功能

- 商品台账：记录商品编号、名称、品类、成色、SKU/库存位、标价、最低接受价、库存和发布状态。
- 发布节奏：记录计划上架日、实际上架日、最后刷新日和刷新间隔；仅对“已上架”商品计算本地待刷新提醒。
- 状态流转：草稿、待上架、已上架、已暂停、已售出、已下架；已售出记录不可重新变回在售。
- 发布文案：根据商品名称、品类、成色、标价、库存和公开瑕疵说明生成可复制文本。
- 数据迁移：按固定字段顺序导入/导出 UTF-8 BOM CSV；导入前整批校验，遇到错误或重复编号时整批拒绝。
- 备份恢复：JSON 备份包含 SHA256 校验；校验失败时不会替换当前台账。

## 三、快速开始

1. 双击“闲鱼商品发布管理助手.exe”。
2. 点击“新增商品”，填写商品编号、名称、品类、成色、标价和库存数量。
3. 商品准备发布时，将状态改为“待上架”；实际发布后改为“已上架”，并填写实际上架日期。
4. 设置刷新间隔（默认 7 天）。工具根据最后刷新日期或实际上架日期显示下次刷新日期。
5. 完成实际刷新后，选择商品并点击“记录刷新”，更新本地刷新日期。
6. 点击“复制发布文案”，人工核对后再粘贴到闲鱼。

## 四、字段和计算口径

- 最低接受价是卖家内部谈价底线，不会出现在复制的发布文案中。
- 刷新间隔允许 1–365 天，默认 7 天；提醒仅是本地日期计算，不代表平台推荐频率。
- 商品链接仅作为文本保存，必须是完整的 HTTP/HTTPS 地址；软件不会访问链接。
- 库存数量允许 0–100000 的整数。库存变化由卖家自行维护。
- “待刷新”只针对状态为“已上架”且有实际上架日期或最后刷新日期的商品。

## 五、CSV 导入与导出

1. 先用“导出 CSV”取得完整字段模板。
2. 使用 Excel 或 WPS 编辑时不要删除、重排表头。
3. 再通过“导入 CSV”导入。商品编号重复、字段缺失、数字或日期无效时整批拒绝，不会只导入一部分。
4. 导出文件使用 UTF-8 BOM；以 =、+、-、@ 开头的文本字段会添加单引号，降低表格公式注入风险。

## 六、备份与恢复

- 建议每次批量导入或修改前点击“备份”。
- 备份文件为 JSON，内含记录内容的 SHA256。
- 恢复前会要求二次确认；文件损坏、格式不支持或 SHA256 不匹配时，当前台账保持不变。

## 七、数据位置与隐私

默认数据位置：%LOCALAPPDATA%\MainlandBusinessTools\xianyu_listing_ledger.json。

软件本地运行，不需要 VPN、ChatGPT、外部 AI、闲鱼账号或云服务。请自行保护电脑、CSV 和备份文件；其中最低接受价、商品链接和备注可能包含卖家内部信息。

## 八、重要限制

- 软件不会连接闲鱼，不保证商品曝光、成交或刷新效果。
- 不自动发布、改价、刷新、发消息、下单或收款。
- 请按闲鱼当前规则和商品实际情况填写信息，发布前人工核对成色、瑕疵、配件、价格及发货说明。
- 定价和最低接受价由卖家自行决定；本工具不是平台估价或交易保证。
