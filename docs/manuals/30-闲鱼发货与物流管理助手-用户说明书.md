# 闲鱼发货与物流管理助手｜用户说明书

## 一、用途

本工具用于闲鱼卖家离线登记订单发货、承运商、运单号、实际发货日期、揽收确认、预计送达、签收及物流异常。适合每天有多笔订单、需要检查发货时限和物流异常的小型卖家。

本工具不登录闲鱼、不读取订单、不连接快递公司、不查询运单，也不会自动发消息或通知买家。所有物流状态由卖家根据实际信息手工维护。

## 二、核心功能

- 发货台账：按发货编号、订单编号和商品/SKU 维护一笔订单的发货记录。
- 发货时限：记录下单日期和承诺发货日期，自动列出仍处于“待打包”且承诺日期已到的记录。
- 揽收跟进：记录承运商、运单号和实际发货日期；状态为“待揽收”时单独提醒。
- 运输跟进：记录揽收确认日期、预计送达日期和签收日期；超过预计送达日期且仍在运输/派送中的记录会提示逾期天数。
- 异常处理：物流状态设为“异常”时必须填写异常说明，便于后续人工核对。
- 运费汇总：统计发货状态、异常件、逾期件和累计运费。
- 数据迁移：支持固定字段顺序的 UTF-8 BOM CSV 导入/导出；整批校验，错误或重复编号时整批拒绝。
- 备份恢复：JSON 备份带 SHA256 校验；校验失败不会替换当前台账。

## 三、快速开始

1. 双击“闲鱼发货与物流管理助手.exe”。
2. 点击“新增发货”，填写发货编号、订单编号、商品/SKU、下单日期和承诺发货日期。
3. 商品打包完成并交给快递后，编辑记录，填写承运商和运单号，将状态改为“待揽收”。保存时会自动补记实际发货日期（如尚未填写）。
4. 快递已揽收后，将状态改为“运输中”或“派送中”；保存时会自动补记揽收确认日期（如尚未填写）。
5. 买家确认收货后，将状态改为“已签收”；保存时会自动补记签收日期（如尚未填写）。
6. 若出现丢件、退回、地址问题等情况，选择“异常”并填写异常说明。
7. 通过“物流汇总”查看发货逾期、等待揽收、预计送达逾期和异常件。

## 四、状态和日期口径

| 状态 | 含义 | 必要信息 |
|---|---|---|
| 待打包 | 尚未交给快递 | 承诺发货日期 |
| 待揽收 | 已交寄，等待快递确认揽收 | 承运商、运单号、实际发货日期 |
| 运输中 | 快递已揽收，运输途中 | 揽收确认日期 |
| 派送中 | 快递员派送中 | 揽收确认日期 |
| 已签收 | 已完成签收 | 签收日期 |
| 异常 | 物流存在需要人工处理的问题 | 异常说明 |
| 已取消 | 发货取消 | 已揽收或已签收的记录不能直接取消 |

- 状态更新按实际业务顺序进行；已签收、已取消为终态，不能直接恢复为运输中。
- 发货逾期：状态仍为“待打包”，且承诺发货日期不晚于今天。
- 等待揽收：状态为“待揽收”，需要卖家人工核对快递是否已揽收。
- 送达逾期：状态为“运输中”或“派送中”，且预计送达日期早于今天。
- 日期使用 YYYY-MM-DD 格式。预计送达日期可以填写未来日期；实际发货、揽收和签收日期不能晚于今天。
- 运费和重量由卖家手工录入，累计运费只汇总本台账已录入的数字，不代表快递账单。

## 五、CSV 导入与导出

1. 先点击“导出 CSV”获取完整字段模板。
2. 使用 Excel/WPS 编辑时不要删除或重排表头。
3. 通过“导入 CSV”导入；必填字段、日期、金额、物流状态和编号都会先整批校验。
4. 如果存在重复发货编号或任一行错误，整批导入会被拒绝，原台账不变。
5. 导出使用 UTF-8 BOM；以 =、+、-、@ 开头的文本字段会添加单引号，降低表格公式注入风险。

## 六、备份与恢复

- 建议在批量导入或大量修改前先备份。
- 备份为 JSON，包含全部记录及 SHA256 校验值。
- 恢复前会二次确认；文件损坏、格式不支持或 SHA256 不匹配时，当前台账保持不变。
- 备份文件可能包含买家备注、订单编号和运单号，请妥善保管。

## 七、数据位置与隐私

默认数据位置：%LOCALAPPDATA%\MainlandBusinessTools\xianyu_shipping_ledger.json。

软件本地运行，不需要 VPN、ChatGPT、外部 AI、闲鱼账号或云服务。请保护电脑、CSV 和备份文件，避免将订单编号、运单号和买家备注公开分享。

## 八、重要限制

- 不连接闲鱼或快递公司，不抓取订单、物流轨迹或买家信息。
- 不自动打印面单、发货、查询物流、通知买家、退款或收款。
- 物流状态和日期由卖家手工录入；请以快递公司实际记录为准。
- 逾期提醒只是本地台账规则，不代表平台处罚、快递承诺或法律结论。
