# 闲鱼退货退款跟进助手｜用户说明书

## 一、产品用途

本工具面向闲鱼个人卖家和小规模二手经营者，用于本地登记退货退款、部分退款、换货和补偿案件，跟踪处理截止日期、下一步动作、买家寄回及卖家收货日期，并汇总已登记退款、补偿和卖家承担的退货运费。

它与“售后纠纷证据链管理助手”分工不同：本工具负责案件状态、金额和时限台账；需要归档聊天截图、订单页面、物流凭证并校验文件哈希时，请使用证据链工具。

## 二、首次使用

1. 双击“闲鱼退货退款跟进助手.exe”。
2. 首次启动显示设备码后，按卖家提供的授权文件说明完成激活。
3. 先用一条虚构测试记录验证新增、编辑、CSV 导出和备份恢复。
4. 确认数据正常后，再录入真实订单。

数据默认保存在当前 Windows 用户的：

`%LOCALAPPDATA%\MainlandBusinessTools\xianyu_return_followup.json`

本工具不登录闲鱼、不读取账号、不抓取订单或聊天、不连接平台或快递接口。

## 三、案件登记字段

- 记录编号、订单编号、商品/SKU、售后类型、申请日期。
- 订单成交金额、买家申请金额、实际退款金额、补偿金额和退货运费。
- 运费承担方、责任归属、处理状态、处理截止日期和下一步动作。
- 买家寄回运单号、买家寄回日期、卖家收货日期、退款完成日期。
- 本地证据目录、处理摘要和内部备注。

金额按人民币元记录，日期统一使用 `YYYY-MM-DD`。实际退款金额不能超过申请金额，申请金额不能超过订单成交金额。买家寄回、卖家收货和退款完成日期按时间顺序校验。

## 四、处理状态

- 待沟通
- 待买家寄回
- 待卖家验收
- 待退款
- 待换货
- 待平台处理
- 已完成
- 已关闭

软件限制不合理的状态跳转；已完成和已关闭为终态。若需要更正已结束案件，请新增更正记录或在备注中说明，不要直接改写历史事实。

## 五、跟进提醒和金额汇总

“处理截止日期”由卖家根据实际页面提示和沟通情况手工填写。软件按本机日期标记：
- 已逾期：截止日期早于今天。
- 今日到期：截止日期为今天。
- 3 日内到期：截止日期在未来 3 天内。

“导出 3 日内跟进”只导出上述需要跟进的未结案件，并按逾期、今日到期、3 日内到期排序。它不会自动联系买家或平台，也不会替你判断平台规则期限。

售后汇总分别显示实际退款、补偿、卖家承担退货运费，以及三项相加的“已登记售后支出”。金额来自卖家手工录入，不是平台账单或会计凭证。

## 六、CSV 导入导出

- “导出全部 CSV”使用 UTF-8 BOM，方便 Windows Excel 正常识别中文。
- CSV 导入要求表头名称和顺序与软件导出文件完全一致。
- 导入前逐行校验；任何一行无效、重复记录编号或超出安全上限，整批不写入。
- 文本字段会对以 `=`、`+`、`-`、`@` 开头的内容添加安全前缀，降低电子表格公式注入风险。

建议先导出空白模板，再复制填入记录，不要手动改动表头。

## 七、备份与恢复

1. 点击“备份”，保存 JSON 文件。
2. 备份包含版本、规则版本、记录和 SHA256 校验值。
3. 点击“恢复备份”前，建议先备份当前数据。
4. 恢复时先验证 SHA256 和记录结构；校验失败不会替换当前台账。

建议每周备份一次，并把备份复制到另一块本地磁盘或受控存储位置。

## 八、使用边界与隐私

- 所有记录保存在本机，不上传云端，不依赖 VPN、ChatGPT 或外部 AI。
- 本地证据目录只是路径备注，不会自动复制、上传或验证其中的文件。
- SHA256 备份校验用于发现备份内容变化，不证明交易事实、证据来源或法律效力。
- 处理截止日期必须由卖家根据实际订单页面和平台通知填写；软件提醒不是闲鱼官方期限、法律意见或平台处理结果。
- 不要把买家姓名、电话、地址等不必要的个人信息写入备注或导出文件。

## 九、建议零售价

建议作为闲鱼财务与交易系列的单品或组合产品测试销售。价格由卖家根据实际反馈决定；任何建议价均不代表已验证成交价。
