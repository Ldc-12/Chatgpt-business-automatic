# 门店优惠券与活动核销助手｜用户说明书

## 一、适用场景与边界

适合便利店、餐饮店、美容美发、洗护和社区服务门店，登记固定金额优惠活动、券码发行、核销、作废和活动优惠成本。

本工具是**单机本地台账**，不是支付系统、电子券平台或营销 SaaS。它不会连接微信、支付宝、POS、短信、闲鱼或其他平台；不会在线创建平台券、自动发券、自动收款或自动抵扣。店员必须先按门店实际流程确认顾客优惠资格，再把核销结果录入软件。

同一份数据文件不支持多台电脑同时编辑。建议指定一台门店电脑作为唯一台账维护端，定期备份。

## 二、首次使用

1. 双击 `MainlandStoreCouponRedemption.exe`。
2. 首次启动会显示本机设备码；取得卖家提供的本产品授权文件后，按提示放入本机授权目录。
3. 数据默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\MainlandBusinessTools\store-coupon-ledger.json`。
4. 建议先用测试活动练习建活动、发行、核销、作废、导出和恢复，再录入真实资料。

## 三、新建营销活动

1. 点击“新建活动”，填写活动名称、每张券优惠金额、最低消费金额、开始/结束日期和发行上限。
2. 优惠金额必须大于 0，最低消费金额不能小于优惠金额；日期必须为 `YYYY-MM-DD` 且开始日期不晚于结束日期。
3. 活动状态为“启用”时才可发行和核销；停用活动不会删除历史券码和核销记录。
4. 活动建立后不能在软件中直接修改金额、日期和发行上限。若规则需要调整，应停用旧活动并新建活动，避免旧券的规则快照被悄悄改变。

## 四、发行、核销和作废

- **发行：**选择活动编号并填写发行张数。软件生成本地唯一券码，单次最多 5000 张，累计不超过活动发行上限。券码只保存在本机台账和导出文件中；需要由门店自行通过已有渠道告知顾客。
- **核销：**在券列表选择一张“未使用”券，填写消费订单号和实际消费金额。实际消费金额必须达到活动最低消费金额；核销优惠按活动固定优惠金额记录。
- **防重复：**一张券只能核销一次；同一订单号不能重复核销多张券。订单号按大小写不敏感方式比较。
- **作废：**只有未使用的券可以作废，必须填写原因；已核销的券不能作废或重新使用。
- **期限：**只能在活动开始日至结束日内发行和核销。活动过期后未使用券会显示在过期统计中，但不会自动改变历史券状态。
- **活动停用：**停用后不能发行或核销；已发生的核销记录保留。

本工具不会验证真实支付流水，也不能证明顾客是否符合门店线下活动规则。核销前请店员核对订单、金额和顾客实际使用情况。

## 五、查询与分页

- 券列表默认按最新生成的券码优先显示，避免新发行的券被旧记录淹没。
- 关键词可搜索券编号、活动编号、活动名称、核销订单号、操作人和备注；状态可筛选全部、未使用、已核销或已作废。
- 列表每页最多显示 100 张券，使用“上一页/下一页”浏览。筛选条件变化后自动回到第一页；数据变更后也会刷新到第一页。
- 筛选只影响当前列表，不会删除或修改台账数据；导出仍按完整台账导出，不受当前筛选条件影响。

## 六、导入、导出和报表

- “导入活动 CSV”只导入活动定义，不导入券码或核销记录，避免外部 CSV 直接伪造已核销状态。
- CSV 必须使用 UTF-8/UTF-8 BOM，表头必须与软件模板完全一致；重复活动编号、无效日期、金额或任意一行错误都会导致整批不写入。
- “导出活动”导出活动规则；“导出优惠券”导出所有券码及当前状态；“导出核销报表”只导出已核销券和实际优惠金额。
- 导出使用 UTF-8 BOM，常见表格软件可直接打开；以 `=`、`+`、`-`、`@` 开头的公式样式文本会加单引号防护，纯负数保留为数值。
- “导出活动汇总”按活动汇总发行、核销、未使用、作废、过期和实际优惠合计。

不要把券码导出文件随意发送给无关人员；券码本身属于门店内部营销资料。

## 七、备份与恢复

1. 点击“备份”，保存 JSON 备份文件。
2. 建议每天营业结束后备份，并复制到受控 U 盘或门店自有加密存储介质。
3. 点击“恢复”会替换当前活动和优惠券数据；恢复前先备份当前文件。
4. 备份含 SHA256 完整性摘要和操作日志哈希链；恢复时会校验文件摘要、活动/券码关系、重复核销订单和日志链。校验失败不会覆盖当前数据。
5. 不要在软件运行时用其他程序手工编辑 JSON 文件。

## 八、重要限制

- 当前版本只支持固定金额优惠，不支持折扣率、满赠、叠加券、跨店共享、自动积分抵扣或线上领券。
- 同一订单只允许登记一张券；多券叠加需要按门店规则人工处理，不要在本工具中重复登记同一订单。
- 不支持导入优惠券和核销流水，防止外部文件注入伪造状态。
- 本地数据不是多用户并发数据库；请指定单一维护电脑并做好备份。
- 本软件不处理真实资金，不连接支付平台，不构成会计、税务、广告或法律合规系统。
- 软件离线运行，不依赖 VPN、ChatGPT、外部 AI、云端账号或平台 API。
