# 门店采购补货与安全库存计划助手｜用户说明书

## 一、产品用途

用于小型门店、便利店、餐饮店和工作室记录商品 SKU、当前库存、预留库存、每日销量、供应商和采购参数，按可解释的规则生成补货建议。适合人工采购前做计划，不会自动下单。

## 二、计算逻辑

- 可用库存 = 当前库存 − 已预留
- 日均销量 = 统计窗口内销量合计 ÷ 统计天数（没有销售记录的日期按 0 计入）
- 补货触发库存 = 日均销量 ×（采购提前期天数 + 安全库存天数）
- 目标库存 = 日均销量 ×（采购提前期天数 + 安全库存天数 + 目标覆盖天数）
- 建议采购量 = max（目标库存 − 可用库存，0），再按整箱数量向上取整；如低于最低起订量，则按整箱数量向上满足起订量
- 预计采购金额 = 建议采购量 × 采购单价

统计窗口为包含今天在内的最近 N 个自然日，N 可设置为 1–365 天。无销量记录时显示“缺少销量数据”，不会把未知需求误判为零销量；录入明确的 0 销量记录后才显示“无销量需求”。

## 三、首次使用

1. 双击 MainlandStoreReplenishmentPlanner.exe。
2. 首次运行按设备码提示完成产品授权。
3. 点击“新增商品”，填写唯一 SKU、商品名称、当前库存、已预留、采购提前期、安全库存天数、目标覆盖天数、整箱数量、最低起订量、采购单价和供应商。
4. 点击“录入销量”，按 SKU、日期和数量登记历史销量。可用 CSV 批量导入。
5. 设置统计天数并点击“刷新”，查看可用库存、日均销量、触发库存、目标库存、建议采购量和预计采购金额。

## 四、CSV 导入导出

- 商品 CSV 表头必须与软件导出的模板完全一致；SKU 不区分大小写且不得重复。
- 销量 CSV 必须引用已存在的 SKU，销售编号不得重复，日期不得晚于今天。
- 每次 CSV 导入先完整校验全部行，任意一行错误会取消整批导入，不会只导入一部分。
- 导出的 CSV 使用 UTF-8 BOM，并对以 =、+、-、@ 开头的文本做公式注入防护。请勿自行删改表头。

## 五、备份与恢复

- 点击“备份”保存 JSON 文件；软件会显示备份文件 SHA256。
- 点击“恢复”选择此前的 JSON 备份。恢复会替换当前商品与销量数据，请先确认已有备份。
- 本地台账和备份都带 SHA256 完整性校验；损坏或被修改的文件会拒绝载入。
- 默认数据路径：%LOCALAPPDATA%\MainlandBusinessTools\store-replenishment.json。

## 六、重要限制

- 补货建议是基于用户自行录入的销量和参数计算的管理参考，不是需求预测保证、供应商承诺或平台官方建议。
- 本软件不会连接 POS、ERP、供应商、电商平台或网络服务，不会自动下单、付款或同步库存。
- 采购提前期、整箱数量、最低起订量和采购单价由用户自行维护；季节性、促销、临时停业和缺货导致的销量偏差需要人工判断。
- 所有数据默认保存在本机；请定期备份，不要把唯一备份放在同一块硬盘。

## 七、版本
