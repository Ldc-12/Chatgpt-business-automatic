# 经营证照与年报提醒助手｜用户说明书

## 一、用途

用于小店、个体经营者和小微企业登记经营证照、年度报告及其他自行维护的经营事项截止日期。支持本地台账、临期/逾期筛选、CSV 导入导出和带 SHA256 校验的备份恢复。

本软件只按用户录入的日期计算提醒，不连接政府平台，不自动申报、续证或提交材料，也不判断某项义务是否适用于你的主体。具体办理范围、法定期限和材料要求，请以主管部门现行规定及正式通知为准。本软件不构成法律、税务或行政合规意见。

## 二、启动与授权

1. 双击 `MainlandBusinessComplianceReminder.exe`。
2. 首次启动显示设备码时，按卖家提供的正式流程取得本产品授权文件。
3. 授权文件放入当前 Windows 用户目录下的 `%LOCALAPPDATA%\MainlandBusinessTools\licenses\经营证照与年报提醒助手.json`。
4. 软件本地运行，不需要 VPN、ChatGPT、外部 AI、政府网站账号或云服务。

## 三、登记事项

点击“新增事项”，建议填写：

- 事项编号：自动生成，也可以改为你自己的唯一编号。
- 事项名称：例如营业执照年报、食品经营许可证续期、消防检查、设备检验或员工健康证复核。
- 事项类型：经营证照、年度报告、税务申报、消防/安全检查、设备检验、员工健康证、其他。
- 登记/开始日期：可留空；填写时不得晚于截止日期。
- 截止日期：必填，请以正式通知或主管部门确认的日期为准。
- 提醒提前天数：默认 30 天，可设为 0–3650 天。
- 状态：待办理、办理中、已完成、已注销。
- 责任人、来源/主管部门、联系方式和备注：用于内部交接。

保存后，列表按截止日期排序。已完成和已注销事项不再参与临期/逾期提醒。

## 四、提醒口径

- 已逾期：截止日期早于今天，且状态不是已完成/已注销。
- 即将到期：剩余天数小于或等于该事项设置的提前提醒天数。
- 正常：尚未进入提醒窗口。
- 无需提醒：状态为已完成或已注销。

“只看临期/逾期”可以快速筛选待处理事项。软件不会在后台发送短信、微信或系统推送，请定期打开软件查看并自行安排办理。

## 五、CSV 导入与导出

- 导入 CSV：必须包含且只能包含软件规定的全部字段；重复事项编号、日期错误或任意一行无效时，整批拒绝，不会只导入部分数据。
- 导出筛选结果：导出当前列表筛选后的记录，使用 UTF-8 BOM，便于 Excel 打开。
- 导出时会对以 `=`、`+`、`-`、`@` 开头的单元格文本加单引号，降低电子表格公式注入风险。

## 六、备份与恢复

- 点击“备份”选择保存位置，生成 JSON 备份并附带 SHA256 校验值。
- 点击“恢复备份”选择备份文件。恢复前会验证文件格式、版本、SHA256 和每条事项字段；任何校验失败都不会替换当前数据。
- 恢复会整体替换当前事项列表，建议先备份当前数据。
- 建议定期把备份复制到独立 U 盘或其他安全位置；备份文件可能包含内部经营信息，请妥善保管。

## 七、数据位置与限制

默认数据文件：`%LOCALAPPDATA%\MainlandBusinessTools\business_compliance.json`。软件不会把台账上传到服务器。

提醒是否准确取决于你录入的截止日期和状态。请自行复核证照名称、适用主体、办理渠道和实际期限，不要把软件提醒当作官方通知。

## 八、建议流程

1. 首次使用先录入一条测试事项。
2. 验证保存、关闭重开、CSV 导出/导入和备份恢复。
3. 确认数据正常后，再录入真实事项。
4. 每周查看临期/逾期列表，完成事项后及时更新状态。
5. 责任人变更或收到主管部门新通知时，立即修改记录并重新备份。
