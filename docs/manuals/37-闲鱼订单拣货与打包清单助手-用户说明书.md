# 闲鱼订单拣货与打包清单助手｜用户说明书

## 一、产品用途

本工具面向需要同时处理多笔闲鱼订单的卖家。它把订单商品明细整理成可执行的 SKU 拣货汇总和逐订单打包清单，减少同款商品漏拣、错规格和重复打包。

本工具不连接闲鱼、不读取账号、不抓取订单。订单数据由卖家手工录入或从自己有权导出的 CSV 文件导入。

## 二、首次使用

1. 双击“闲鱼订单拣货与打包清单助手.exe”。
2. 首次运行会显示设备码；按卖家提供的产品授权文件说明完成授权。
3. 数据默认保存在当前 Windows 用户的 %LOCALAPPDATA%\\MainlandBusinessTools\\xianyu_pick_pack.json。
4. 建议先用两笔测试订单录入同一 SKU，确认拣货汇总合并数量正确，再录入正式订单。

## 三、录入与进度

每一行代表一个订单中的一种商品/规格。必填字段为订单编号、商品名称和数量；SKU 可填写卖家自己的库存编码，未填写时按商品名称归组。

- **新增明细**：录入订单、商品、规格、数量及买家备注。
- **编辑进度**：填写已拣数量、已打包数量和包裹编号。
- **处理状态**：由数量自动计算为待拣货、拣货中、已拣货、打包中或已打包。
- 已拣数量不能超过订单数量；已打包数量不能超过已拣数量。
- 同一 SKU 和规格会汇总到同一拣货组；不同规格会分开显示。

## 四、CSV 导入与导出

CSV 导入至少需要三列：订单编号、商品名称、数量。可选列包括：明细编号、SKU、规格/成色、已拣数量、已打包数量、包裹编号、订单日期、买家备注、内部备注。

支持 UTF-8/UTF-8 BOM 和 GB18030。导入前会整批校验；只要有一行不合规或明细编号重复，整批拒绝，不会只导入一部分。未提供明细编号时，工具会按该 CSV 行内容生成稳定编号；重复导入同一文件会被识别为重复明细。

- **导出明细**：导出逐订单商品行。
- **导出拣货汇总**：按 SKU/规格汇总需求、已拣和待拣数量。
- **导出打包清单**：保留订单级明细、包裹编号和处理状态。

导出使用 UTF-8 BOM，并对以 = + - @ 或单引号开头的文本进行表格公式注入防护；重新导入本工具导出的文件会恢复原始文本。

## 五、备份与恢复

- 点击“备份”，保存 JSON 备份及 SHA256 校验值。
- 点击“恢复备份”，选择备份文件。恢复会整体替换当前台账。
- 若 SHA256 不匹配或备份结构无效，恢复会被拒绝，当前数据保持不变。
- 建议每周备份一次，并把备份复制到独立磁盘或可信位置。

## 六、使用边界

- 本工具只负责卖家内部拣货与打包清单，不会自动发货、联系买家或更新闲鱼订单状态。
- SKU、商品名称和数量应与卖家实际库存核对；汇总结果不能替代发货前人工复核。
- 包裹编号由卖家自行填写，不会生成快递面单或查询物流。
- 数据保存在本机；卸载或更换电脑前请先导出 CSV 并制作 JSON 备份。

## 七、版本与离线说明

本说明书对应“闲鱼订单拣货与打包清单助手”大陆 Windows 单机版。无需 Python、VPN、ChatGPT、外部 AI 或云服务。
