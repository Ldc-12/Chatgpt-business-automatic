# 门店采购订单与到货跟踪助手｜用户说明书

## 一、产品用途

本工具用于小店、便利店、餐饮及服务门店登记采购单明细，跟踪供应商分批到货，并快速识别预计到货日已过但合格数量仍未齐的采购项目。它补充“采购补货计划”和“收货验收差异”两个环节，不替代会计软件或供应商正式对账单。

## 二、运行环境与数据位置

- Windows 10/11，双击 MainlandStorePurchaseOrderTracker.exe 启动。
- 数据默认保存在 %LOCALAPPDATA%\MainlandBusinessTools\store-purchase-orders.json。
- 本地离线运行，不需要 VPN、ChatGPT、外部 AI、闲鱼账号或云服务。
- 首次启动如显示设备码，请按卖家提供的本产品授权文件说明操作。

## 三、首次建立采购单

1. 点击“新增采购明细”。
2. 填写明细编号（留空时自动生成）、采购单号、供应商、下单日期、预计到货日期、采购员、SKU、商品名称、订购数量和采购单价。
3. 同一采购单号可以有多条 SKU 明细；同一采购单号的供应商、下单日期、预计到货日期和采购员必须保持一致。
4. 保存后会自动写入本机 JSON 台账。重新启动软件会自动读取。

## 四、登记分批到货

1. 在主列表选中对应 SKU 明细，点击“登记分批到货”。
2. 填写到货记录编号（留空时自动生成）、到货日期、合格数量、破损数量、拒收数量及处理备注。
3. 同一采购明细可以登记多次到货，系统累计各批次数量。
4. “剩余待到货”按合格数量计算；破损和拒收单独统计，不会自动视为合格交付。
5. 合格数量达到订购数量时显示“已到齐”；超过预计到货日期仍未齐时显示“逾期部分到货”或“逾期未到货”。

## 五、报表与 CSV

- “导出采购明细”：导出采购单和 SKU 明细。
- “导出到货记录”：导出每一批到货记录。
- “导出到货状态报告”：导出累计到货、破损、拒收、剩余待到货、金额和状态。
- “导出供应商汇总”：按供应商统计采购单数、逾期明细和待到货金额。
- 导入 CSV 前先导入采购明细，再导入对应到货记录。表头必须与软件导出模板一致。
- 支持 UTF-8（含 BOM）和 GB18030。导入采用整批校验，发现重复编号、未知明细或字段错误时整批取消。
- 导出会对以 =、+、-、@ 等字符开头的文本做电子表格公式注入防护；重新导入本软件导出的 CSV 时会恢复原始文本。

## 六、备份与恢复

1. 点击“备份”，选择保存位置，软件会生成带 SHA256 校验值的 JSON 备份。
2. 建议每周备份一次，并将备份复制到另一块磁盘或可靠的移动存储设备。
3. 点击“恢复”选择备份文件；恢复前会再次校验格式和 SHA256。
4. 恢复会替换当前全部采购明细和到货记录。请先备份当前数据，再执行恢复。

## 七、统计口径与限制

- “合格到货”才冲减待到货数量；破损和拒收不会冲减采购缺口。
- 待到货金额 = 剩余待到货数量 × 采购单价，仅供采购跟进参考，不等同应付账款、发票金额或实际付款金额。
- 逾期按本机当前日期与预计到货日期比较；本工具不自动读取物流轨迹，也不会向供应商发送催货消息。
- 超收数量单独列示，不自动形成采购付款或库存入库凭证。
- 请以合同、采购单、验收单和双方确认结果为准，重要付款及纠纷事项应人工复核。

## 八、建议工作流程

采购补货计划 → 建立采购订单 → 分批登记到货 → 对照收货验收差异 → 供应商对账与应付账龄。各工具的数据文件独立保存，如需跨工具使用，请通过 CSV 导出后按模板导入。
