# 闲鱼询价转化与议价复盘助手｜用户说明书

## 一、适用场景

适合需要手工记录闲鱼买家询价、买家报价、卖家回价、成交结果和后续跟进的小卖家。它帮助卖家复盘哪些商品更容易成交、通常让价多少、哪些买家需要继续跟进。

本软件是 Windows 单机工具，不登录闲鱼、不读取平台消息、不自动发布商品、不自动联系买家，也不查询实时行情。

## 二、首次启动与数据位置

1. 双击 MainlandXianyuNegotiationReview.exe。
2. 首次使用会显示设备码；请按卖家提供的授权文件说明激活。
3. 默认数据保存在 %LOCALAPPDATA%\MainlandBusinessTools\xianyu_negotiation_review.json。
4. 建议先录入两三条测试记录，验证保存、导出和备份恢复后再录入正式数据。

授权文件放在 %LOCALAPPDATA%\MainlandBusinessTools\licenses\闲鱼询价转化与议价复盘助手.json。

## 三、记录字段

- 商品编号、订单编号、商品名称、SKU：用于把商品、订单和规格分开记录。
- 买家备注：建议只写昵称或内部代号，不要录入身份证号、银行卡、完整手机号等不必要的个人敏感信息。
- 询价日期、最近沟通日期、下次跟进日期：日期格式必须为 YYYY-MM-DD；最近沟通和下次跟进日期不能早于询价日期。
- 标价、最低接受价、买家报价、卖家回价、成交价：按元录入，最多保留两位小数；金额不能为负数。
- 商品成本、平台费用、运费成本：用于估算成交后的毛利。
- 结果：待回复、议价中、已成交、未成交、已取消。
- 未成交原因、内部备注：用于复盘价格、成色、发货、时机等因素。

只有结果为“已成交”时才允许填写大于 0 的成交价。低于最低接受价的实际成交不会被阻止，但会单独计数，方便卖家复盘是否存在过度让价。

## 四、主要操作

### 1. 新增、编辑和删除

点击“新增询价”录入每次询价。一个商品可以有多条买家询价记录；不要把不同买家的询价覆盖到同一条记录。选中表格行后可以编辑或删除。

### 2. 到期跟进

“导出到期跟进”会筛选结果为“待回复”或“议价中”，且下次跟进日期不晚于电脑本地今天的记录。已成交、未成交和已取消记录不会进入待跟进清单。
在主界面点击“仅看待跟进”，表格会立即只显示今日到期及已逾期的开放记录；再次点击“显示全部”恢复完整列表。该筛选可与上方商品编号、商品名称、订单号、SKU 或买家备注搜索同时使用，不会修改或删除任何记录。
导出的到期跟进 CSV 会额外增加“逾期天数”和“跟进提示”两列：今天到期显示“0 / 今日到期”，逾期记录显示实际逾期天数。它们是按导出当天电脑本地日期计算的派生字段，不会写入或改变原始台账。

### 3. 商品转化复盘

“导出商品复盘”按商品编号和 SKU 分组，输出询价数、成交数、成交转化率、平均标价、平均成交价、平均议价幅度、成交金额、估算毛利和低于最低接受价成交笔数。

估算毛利 = 成交价 − 商品成本 − 平台费用 − 运费成本。未计入的人工、包装、退货、税费等成本会使估算结果偏高，请自行补充经营核算。

平均议价幅度 = 已成交记录的（标价 − 成交价）÷ 标价，再按成交记录取平均。该指标不是平台官方统计口径。

### 4. CSV 导入导出

- 支持 UTF-8、UTF-8 BOM 和 GB18030 编码。
- 单个 CSV 最大 20 MB；软件会先检查文件大小，并限制实际读取字节数。超出上限会拒绝导入，不会改动现有台账。
- 导入 CSV 必须包含商品编号、商品名称、询价日期三列；其他字段可留空。
- 导入前会校验整批数据和记录编号，任何一行失败都会拒绝整批导入，不会只导入一部分。
- 导出文件使用 UTF-8 BOM；对以 =、+、-、@ 开头，以及在前导空白、制表符或换行后出现这些字符的文本进行公式注入防护；重新导入时会还原原始文本。
- 支持完整询价明细、到期跟进清单和商品复盘报表三种导出。

### 5. 备份与恢复

点击“备份”生成带 SHA256 校验值的 JSON 文件。恢复时先校验文件结构和 SHA256；校验失败不会覆盖当前台账。恢复成功会替换当前台账，建议恢复前先做一次备份。

## 五、统计口径和限制

- 转化率 = 已成交询价记录数 ÷ 该商品/SKU 的询价记录数。
- 同一买家对同一商品多次询价会按多条记录统计；请保持记录口径一致。
- 估算毛利只使用录入的成交价、商品成本、平台费用和运费成本，不代表财务报表或税务利润。
- 本软件不抓取闲鱼数据，不保证买家回复或成交，也不提供平台规则、行情或法律建议。

## 六、常见问题

**导入失败怎么办？** 检查 CSV 表头、日期格式、金额是否为非负数字、记录编号是否重复。可先用软件导出一份 CSV 作为模板。

**为什么已成交记录不能留空成交价？** 因为成交转化率和毛利复盘需要实际成交价；未成交记录请把结果改为“未成交”或其他非成交状态。

**为什么恢复后旧数据消失？** 恢复是整份替换，不是合并。请先备份当前台账。

**软件会自动读取闲鱼聊天吗？** 不会。所有询价信息由卖家手工录入，软件完全本地运行。
