# 门店条码与价签批量打印助手｜用户说明书

## 一、适用场景

适合便利店、工作室、小型仓库和闲鱼卖家维护 SKU、商品名称、规格、售价及条码，并按商品打印数量批量生成价签 PDF。

本软件只生成本地 Code128 条码和 A4 价签 PDF，不连接收银系统、商品平台、打印机云服务或网络接口。打印前请先用普通纸测试版式和实际标签纸尺寸。

## 二、首次启动与数据位置

1. 双击 MainlandBarcodeLabelStudio.exe。
2. 首次使用会显示设备码；按卖家提供的授权文件说明激活。
3. 商品目录默认保存在 %LOCALAPPDATA%\MainlandBusinessTools\barcode-labels.json。
4. 授权文件放在 %LOCALAPPDATA%\MainlandBusinessTools\licenses\门店条码与价签批量打印助手.json。
5. 建议先添加 1–2 条测试商品，验证 CSV、备份和 PDF 输出，再录入正式目录。

## 三、商品字段与校验规则

- **SKU**：必填，1–18 位字母、数字、点、下划线或连字符；首位必须是字母或数字；不区分大小写不能重复。
- **商品名称**：必填，最多 80 个字符。
- **规格**：可选，最多 60 个字符，例如 500g、12 入、黑色。
- **价格**：按元录入，最多两位小数，不能为负数。
- **条码**：可留空，留空时使用 SKU；当前版本生成 Code128，支持 1–18 位可打印 ASCII 字符，首位必须是字母或数字；不区分大小写不能重复。
- **打印数量**：每个商品 1–9999 张，必须为整数。

同一商品的不同规格建议使用不同 SKU 和条码，避免扫码时混淆。

## 四、主要操作

### 1. 新增和修改商品

在表单填写 SKU、商品名称、规格、价格、条码和打印数量，点击“新增 / 保存”。双击列表中的商品可以载入表单后修改。SKU 和条码重复时，软件会拒绝保存。

### 2. 搜索

搜索框支持 SKU、商品名称、规格和条码。搜索只影响列表显示，不会删除或修改商品记录。

### 3. 导入 CSV

CSV 必须使用软件导出的表头，列顺序为：

SKU,商品名称,规格,价格,条码,打印数量

支持 UTF-8（含 BOM）和 GB18030。导入前会整批校验：只要一行字段无效、SKU 重复或条码重复，就不会导入任何一行。单个 CSV 最大 25 MiB、最多 50,000 条记录。

### 4. 导出 CSV

导出的 CSV 使用 UTF-8 BOM，方便用 Excel 打开。商品名称、规格等文本若以 =、+、- 或 @ 开头，会添加单引号作为公式注入防护；这是安全导出处理，不是商品原始数据被修改。

### 5. 备份与恢复

- “备份”会生成带 SHA256 校验值的 JSON 文件。
- “恢复备份”会先检查格式、版本和 SHA256，校验通过后才替换当前商品目录。
- 恢复会覆盖当前目录，操作前建议先备份。
- 台账和备份文件均有 100 MiB 安全上限。

### 6. 生成价签 PDF

点击“生成价签 PDF”，软件按每条商品的“打印数量”展开标签，生成 A4 PDF。默认每页 3 列 × 8 行，共 24 张；每张包含商品名称、规格、售价、Code128 条码和条码文本。

单次最多生成 20,000 张。商品条码过宽、商品目录为空或超过数量上限时，软件会提示错误，不会生成不完整文件。

## 五、打印建议

1. 先用普通 A4 纸打印一页，检查条码清晰度、文字和标签边界。
2. 打印对话框选择“实际大小 / 100%”，不要选择“适合页面”或自动缩放。
3. 确认标签纸的单张尺寸、列数和行距与本软件的 A4 固定版式相符；不匹配时请先调整标签纸或使用 PDF 打印软件的自定义纸张功能。
4. 用实际扫码设备测试条码后，再批量打印。
5. 条码内容由卖家自行维护；请确认 SKU 与商品实物一致。

## 六、数据安全与限制

- 数据只保存在本机 %LOCALAPPDATA%\MainlandBusinessTools，不会上传。
- CSV 导入采用整批校验，导出对公式注入做保护。
- JSON 台账和备份均使用 SHA256 校验；SHA256 用于发现意外损坏或修改，不是云端备份，也不提供密码加密。
- 软件不自动同步库存、价格或收银系统；商品数量、售价和条码需人工核对。
- 本工具生成的是 Code128，不代表 GS1/EAN 商品编码已注册或符合零售平台的编码规则。需要使用正式商品条码时，请使用已合法取得的条码值并自行核实适用要求。
- 不依赖 VPN、ChatGPT、外部 AI 或云服务。

建议定期把备份文件复制到独立 U 盘或其他安全位置，避免电脑损坏导致数据丢失。
