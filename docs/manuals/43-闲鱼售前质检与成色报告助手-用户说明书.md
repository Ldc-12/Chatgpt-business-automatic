# 闲鱼售前质检与成色报告助手｜用户说明书

## 一、适用场景

适合出售手机、电脑、相机、数码配件和其他二手商品的卖家，在上架前建立逐件自检记录，整理外观、功能、配件、瑕疵和维修/拆修历史，并生成可打印的 PDF 检查报告及可复制的商品披露文案。

## 二、主要功能

- 按商品编号建立独立质检记录，可编辑、单条删除或 Ctrl/Shift 多选批量删除，并支持本地搜索。
- 记录品类、品牌型号、成色等级、检测日期和检测人。
- 分别填写外观检查、功能检测结论、具体功能检查记录和配件清单。
- 单独记录瑕疵说明、维修/拆修历史；空白项目会在报告中标注为未填写，不会自动视为通过。
- 仅允许填写最多 6 位序列号尾号，避免在台账和报告中保存完整序列号。
- 为每件商品生成中文 PDF 自检报告，并生成可复制到商品描述的披露文案；PDF 不包含建议售价、购入成本和内部备注。
- 支持在列表中按 Ctrl/Shift 多选商品，一次导出 ZIP 报告包；包内包含逐件 PDF、CSV 索引和逐份 PDF 的 SHA256 清单。
- 支持 CSV 整批导入、公式安全导出，以及带 SHA256 校验的 JSON 备份/恢复。

## 三、首次使用

1. 双击 MainlandXianyuConditionReport.exe。
2. 点击“新增记录”，填写商品编号、名称、品类和检测日期。
3. 逐项完成外观、功能、配件、瑕疵和维修历史检查；未检查的项目请明确留空或选择“未完成检测”。
4. 保存后选中商品，可点击“生成质检 PDF”或“复制披露文案”。如需一次整理多件商品，可按住 Ctrl/Shift 多选，再点击“批量导出报告包”；删除多条记录时也可多选后点击“删除记录”，程序会显示数量并在确认后一次保存。
5. 上架前请逐项核对报告与实物，特别是瑕疵、维修史和功能异常。

## 四、CSV 导入导出

- 导入支持 UTF-8、UTF-8 BOM 和 GB18030 编码。
- CSV 必须包含“商品编号、商品名称、品类、检测日期”四列；导入前会整批校验，任何一行不合法都不会部分写入。
- CSV 文件最大 20 MiB；程序在读取前检查大小，并限制实际读取字节数。
- 导出使用 UTF-8 BOM，并对可能触发电子表格公式的文本添加安全前缀；重新导入时会恢复原文本。
- 建议先导出一份样例 CSV，再按原表头整理数据。

批量报告 ZIP 包含逐件 PDF、UTF-8 BOM 的 CSV 索引、manifest.json（记录每份 PDF 的字节数和 SHA256）及使用说明。索引不包含建议售价、购入成本和内部备注；PDF 同样不显示这三项内部信息。导出前会验证 ZIP CRC，生成失败不会覆盖已有同名文件。

## 五、备份与恢复

- 点击“备份”生成带 SHA256 校验的 JSON 文件。
- 恢复会替换当前台账，建议先对当前数据做一次备份。
- 若备份内容被修改或校验失败，程序会拒绝恢复，不会覆盖现有数据。
- 默认数据目录：%LOCALAPPDATA%\MainlandBusinessTools。

## 六、报告范围与重要限制

- 本工具只整理卖家手工录入的自检信息，不连接或抓取闲鱼，不自动发布商品、联系买家或查询品牌数据库。
- PDF 是卖家自检记录，不是第三方检测、品牌官方鉴定、国家认证、法律意见或无瑕疵保证。
- “成色等级”由卖家自行判断；不同品类、品牌和买家对成色的理解可能不同，应在文案中说明判断依据。
- 空白检查项目表示未填写，不代表通过。无法完成测试时应选择“未完成检测”，不要推断为正常。
- 不要录入完整 IMEI、序列号、身份证号、手机号或其他不必要的个人信息；序列号字段只填写尾号。
- 建议使用普通测试数据先验证保存、CSV、PDF 和备份恢复，再录入正式商品。

## 七、授权与运行环境

Windows 10/11 单机运行；首次启动会显示本机设备码，需要卖家签发本产品专属授权文件。授权文件放入 %LOCALAPPDATA%\MainlandBusinessTools\licenses\闲鱼售前质检与成色报告助手.json。本工具不需要 VPN、ChatGPT、外部 AI 或云服务。
